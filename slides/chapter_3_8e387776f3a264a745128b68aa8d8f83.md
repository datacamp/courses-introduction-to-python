```

```out

```py
fam.index("mom") # "Call method index() on fam"
```{{1}}

```out

```{{2}}

```py
fam.count(1.73)
```{{3}}

```out

```{{4}}

`@script`
Să presupunem că vrei să obții indexul șirului „mom" din lista fam. fam este un obiect Python de tip listă și are o metodă numită index. Ca să apelezi metoda, folosești notația cu punct, ca în exemplul de față. Singurul argument este șirul „mom", adică elementul al cărui index îl cauți.

Python returnează 4, care este într-adevăr indexul șirului „mom". Am apelat metoda index pe lista fam, iar rezultatul a fost 4. Similar, pot folosi metoda count pe lista fam ca să număr de câte ori apare 1,73 în listă.

Python îmi dă 1, ceea ce are sens, pentru că doar liz are înălțimea de 1,73 metri.

Dar listele nu sunt singurele obiecte Python care au metode asociate. Și tipurile float, integer, boolean și șir

```out

`@script`
Ca să fie complet clar: în Python, totul este un obiect, iar fiecare obiect are metode specifice. În funcție de tipul obiectului, listă, șir, float sau altceva, metodele disponibile sunt diferite. Un obiect de tip șir, ca sister, are metoda replace, dar o listă ca fam nu are această metodă, după cum poți vedea din această eroare.

`@script`
mai am un lucru important de spus. Unele metode pot modifica obiectul pe care sunt apelate. Să revenim la lista fam și să apelăm metoda append pe ea. Ca argument, îi transmitem un șir pe care vrem să îl adăugăm în listă.

Python nu generează niciun rezultat, dar dacă verificăm din nou lista fam, vedem că a fost extinsă cu șirul „me".

Hai să facem asta din nou, de data aceasta ca să adaug înălțimea mea în listă.

Din nou, lista fam a fost extinsă.

Este destul de util, pentru că poți scrie cod concis ca să îți actualizezi structurile de date din mers. Totuși, poate fi și riscant. Unele apeluri de metode nu modifică obiectul pe care sunt apelate, în timp ce altele îl modifică, așa că fii atent.
