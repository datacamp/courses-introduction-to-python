`@script`
假设你想知道字符串 "mom" 在 fam 列表里的索引位置。fam 是一个列表类型的 Python 对象，它自带了一个叫 index 的方法。用点号 . 就能直接调用它，像这样就行。传入唯一的参数 "mom"，也就是你想查询索引的元素。

Python 就会返回 4 — 这正是 "mom" 对应的索引。这里我们是在 fam 列表“上”调用了 index 方法，得到了结果 4。同理，你还可以在 fam 上调用 count 方法，统计 1.73 在列表里出现了几次。

Python 会返回 1，这完全合理，因为只有 liz 的身高是 1.73米。

不过，列表可不是唯一拥有专属方法的 Python 对象，像浮点数、整数、布尔值和字符串这些对象，

`@script`
还要提醒你最后一点。有些方法在调用时会直接修改对象本身。我们拿回 fam 列表，在它上面调用 append() 方法，把想加进列表的字符串作为参数传递进去。

Python 并没有打印任何输出，但如果你再去查一下 fam 列表，就会发现它的末尾已经成功追加了字符串 "me"。

我们再来一次，这次把我的身高也加进去。

fam 列表又被动态扩展了。

这个功能非常方便，能让你编写非常简洁的代码来随时更新数据。但它也隐藏着风险：有的方法在调用结束后不会改变原对象，而有的方法却会直接改动原数据，所以使用的时候一定要多加留心。
