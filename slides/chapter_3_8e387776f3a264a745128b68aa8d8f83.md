```{{1}}

```{{3}}

```{{4}}

`@script`
สมมติว่าต้องการหาตำแหน่งของสตริง "mom" ในลิสต์ fam ลิสต์ fam เป็นออบเจกต์ประเภทลิสต์ และมีเมธอดชื่อ index ในการเรียกใช้เมธอด ให้ใช้จุด (.) เชื่อมชื่อออบเจกต์กับชื่อเมธอด แล้วส่งสตริง "mom" เป็น input

Python คืนค่า 4 ซึ่งถูกต้อง เพราะ "mom" อยู่ที่ตำแหน่งที่ 4 นอกจากนี้ยังใช้เมธอด count กับลิสต์ fam เพื่อนับว่า 1.73 ปรากฏกี่ครั้งในลิสต์ได้อีกด้วย

Python คืนค่า 1 ซึ่งสมเหตุสมผล เพราะมีแค่ liz เท่านั้นที่สูง 1.73 เมตร

แต่ลิสต์ไม่ใช่ออบเจกต์เดียวที่มีเมธอด ทศนิยม จำนวนเต็ม บูลีน และสตริง

`@script`
ยังมีอีกเรื่องหนึ่งที่อยากบอก เมธอดบางตัวสามารถเปลี่ยนแปลงออบเจกต์ที่เรียกใช้ได้โดยตรง ลองดูลิสต์ fam แล้วเรียกใช้เมธอด append โดยส่งสตริงที่ต้องการเพิ่มเข้าไปในลิสต์เป็น input

Python ไม่แสดงผลลัพธ์ใดๆ แต่เมื่อตรวจสอบลิสต์ fam อีกครั้ง จะเห็นว่ามีสตริง "me" เพิ่มเข้ามาแล้ว

ลองทำอีกครั้ง คราวนี้เพิ่มส่วนสูงของตัวเองเข้าไปในลิสต์

ลิสต์ fam ก็ถูกขยายเพิ่มอีกครั้ง

เรื่องนี้มีประโยชน์มาก เพราะเขียนโค้ดสั้นๆ เพื่ออัปเดตโครงสร้างข้อมูลได้ทันที แต่ต้องระวังด้วย เพราะเมธอดบางตัวเปลี่ยนแปลงออบเจกต์ต้นทาง ในขณะที่บางตัวไม่ได้เปลี่ยน
