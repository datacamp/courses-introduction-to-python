fam.count(1.73)

`@script`
假設你想知道字串 "mom" 在 fam 串列裡的索引位置。fam 是一個串列型別的 Python 物件，它自帶了一個叫 index 的方法。用點號 . 就能直接呼叫它，像這樣就行。傳入唯一的參數 "mom"，也就是你想查詢索引的元素。

Python 就會回傳 4，這正是 "mom" 對應的索引。這裡我們是在 fam 串列「上」呼叫了 index 方法，得到了結果 4。同理，你還可以在 fam 上呼叫 count 方法，統計 1.73 在串列裡出現了幾次。

Python 會回傳 1，這完全合理，因為只有 liz 的身高是 1.73 米。

不過，串列可不是唯一擁有專屬方法的 Python 物件，像浮點數、整數、布林值和字串這些物件，
