`@script`
Řekněme, že chceš zjistit index řetězce "mom" v seznamu fam. fam je objekt Pythonu typu seznam a má metodu index. Metodu zavoláš pomocí tečkové notace, takto. Jediným vstupem je řetězec "mom", tedy prvek, jehož index hledáme.

Python vrátí 4, což je skutečně index řetězce "mom". Metodu index jsem zavolal „na" seznamu fam a výsledek byl 4. Podobně můžu na seznamu fam zavolat metodu count a zjistit, kolikrát se v seznamu vyskytuje hodnota 1.73.

Python vrátí 1, což dává smysl — jen liz je vysoká 1.73 metru.
