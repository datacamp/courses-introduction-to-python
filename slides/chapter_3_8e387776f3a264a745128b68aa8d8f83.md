```py

fam.count(1.73)
```{{3}}

`@script`
Допустим, вам нужно узнать индекс строки «mom» в списке fam. Список fam — это объект Python типа list, и у него есть метод index. Чтобы вызвать метод, используется точечная нотация, вот так. В качестве аргумента передаём строку «mom» — тот элемент, индекс которого нас интересует.

Python возвращает 4 — это действительно индекс строки «mom». Мы вызвали метод index на списке fam, и получили результат 4. Аналогично, метод count на том же списке позволяет подсчитать, сколько раз значение 1,73 встречается в списке.

Python вернёт 1, и это логично: рост 1,73 метра есть только у liz.

Однако методы есть не только у списков. Они также доступны для объектов типа float, int, bool и string.

`@script`
хочу рассказать ещё об одном важном нюансе. Некоторые методы изменяют сам объект, на котором они вызываются. Вернёмся к списку fam и вызовем на нём метод append. В качестве аргумента передадим строку, которую хотим добавить в список.

Python не выводит никакого результата, но если снова обратиться к списку fam, мы увидим, что он пополнился строкой «me».

Повторим то же самое, на этот раз добавив в список мой рост.

Список fam снова изменился.

Это очень удобно: с помощью компактного кода можно обновлять структуры данных прямо на ходу. Однако здесь стоит быть внимательными. Одни методы не изменяют объект, другие — изменяют. Учитывайте это в своей работе.
