```out

```py
fam.index("mom") # "Викликати метод index() на fam"
```{{1}}

```out

```{{2}}

```py
fam.count(1.73)
```{{3}}

```out

```{{4}}

`@script`
Припустімо, ви хочете отримати індекс рядка "mom" у списку fam. fam це об'єкт Python типу list і він має метод index. Щоб викликати метод, використовуйте крапковий запис, ось так. Єдине введення це рядок "mom", елемент, для якого ви хочете отримати індекс.

Python повертає 4. Це дійсно індекс рядка "mom". Я викликав метод index «на» списку fam, і результатом було 4. Так само можна використати метод count для списку fam, щоб порахувати, скільки разів 1,73 трапляється у списку.

Python дає 1. Це логічно, адже лише liz має зріст 1,73 метра.

Але списки не єдині об'єкти Python, які мають методи. Також числа з плаваючою крапкою, цілі числа, булеві значення та рядки

```{{4}}

`@script`
є ще одна річ, про яку хочу сказати. Деякі методи можуть змінювати об'єкти, для яких їх викликають. Повернімося до списку fam і викличмо для нього метод append. Як аргумент передаємо рядок, який хочемо додати до списку.

Python не виводить результат. Але якщо знову переглянемо список fam, побачимо, що його доповнено рядком "me".

Зробімо це ще раз. Цього разу додамо до списку мій зріст.

Знову список fam було розширено.

Це зручно, адже можна коротко оновлювати структури даних просто під час роботи. Але це може бути й небезпечно. Деякі виклики методів не змінюють об'єкт, для якого їх викликають, а інші змінюють. Тож будьте уважні.
