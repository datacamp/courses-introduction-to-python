`@script`
Funkcje nie są dla ciebie zupełną nowością, bo już z nich korzystałeś. Na przykład `type` to funkcja, która zwraca typ danej wartości. Ale czym właściwie jest funkcja? Mówiąc prosto, to fragment kodu wielokrotnego użytku, który rozwiązuje konkretne zadanie. Możesz wywoływać funkcje zamiast pisać kod samodzielnie. Zobaczmy to na przykładzie.

`@script`
Załóżmy, że masz listę zawierającą wzrosty członków twojej rodziny, `fam`.

Powiedzmy, że chcesz znaleźć największą wartość na tej liście. Zamiast pisać własny kod w Pythonie, który przejrzy listę i znajdzie najwyższą wartość, możesz użyć wbudowanej funkcji `max`. To jedna z wbudowanych funkcji Pythona, podobnie jak `type`. Wystarczy przekazać `fam` do `max` w nawiasach.

Wynik jest zgodny z oczekiwaniami. To 1,89, czyli największa liczba na liście.

Funkcja `max` zadziałała tu jak czarna skrzynka.

## round()

```yaml
type: FullSlide
key: b6626f6bff
code_zoom: 62
```

`@part1`
```py
round(1.68, 1)
```{{1}}

```out
1.7
```{{1}}

```py
round(1.68)
```{{2}}

```out
2
```{{2}}

```py
help(round) # Open up documentation
```{{3}}

```out
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
Kolejną wbudowaną funkcją jest `round`. Przyjmuje ona dwa argumenty wejściowe. Pierwszy to liczba, którą chcesz zaokrąglić, a drugi to precyzja zaokrąglenia, czyli liczba miejsc po przecinku. Powiedzmy, że chcesz zaokrąglić 1,68 do jednego miejsca po przecinku. Pierwszy argument to 1,68, drugi to 1. Argumenty oddzielamy przecinkiem.

Ale to nie wszystko. Można też wywołać funkcję `round` z tylko jednym argumentem, tak jak tutaj. Python zauważy, że nie podałeś drugiego argumentu, i automatycznie zaokrągli liczbę do najbliższej liczby całkowitej.

Żeby zrozumieć, dlaczego oba podejścia działają, zajrzyjmy do dokumentacji. Możesz to zrobić za pomocą kolejnej funkcji, `help`, w taki sposób.

Widać, że `round` przyjmuje dwa argumenty wejściowe.
