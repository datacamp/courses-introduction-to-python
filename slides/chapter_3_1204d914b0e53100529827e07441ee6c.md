`@part1`

```{{1}}

```out

```py

```{{2}}

```out

```{{2}}

```py
help(round) # Open up documentation
```{{3}}

```out
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
こうした組み込み関数のもう一つが round() です。2つの入力を使います。1つ目は丸めたい数値、2つ目は丸める精度、つまり小数点以下を何桁残すかです。1.68 を小数第1位に丸めたいとします。最初の入力は 1.68 で、2番目の入力は 1 です。入力はカンマで区切ります。

ただし、これだけではありません。このように、round() 関数は入力が1つだけでも問題なく呼び出せます。今回は、Pythonが2つ目の入力が指定されていないことを判断し、自動的に数値を最も近い整数に丸めます。

なぜどちらの方法でもうまくいくのかを理解するために、ドキュメントを開いてみましょう。これは、さらに別の関数である help() を使って、このように行えます。

round() は2つの入力を受け取るようです。
