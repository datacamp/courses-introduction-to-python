```{{3}}

```out
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
En annan inbyggd funktion är round. Den tar två indata: först ett tal du vill avrunda, och sedan precisionen, alltså hur många decimaler du vill behålla. Säg att du vill avrunda 1,68 till en decimal. Det första indatat är 1,68 och det andra är 1. Du separerar indatan med ett kommatecken.

Men det finns mer att säga. Det är fullt möjligt att anropa round med bara ett indatat, så här. Den här gången förstår Python att du inte angett det andra indatat och väljer automatiskt att avrunda till närmaste heltal.

För att förstå varför båda sätten fungerar kan vi titta i dokumentationen. Det gör du med ytterligare en funktion, help, så här.

Där ser vi att round tar två indata.
