round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
另一个内置函数是 round()。它接收两个输入：其一，你想要进行四舍五入的数字；其二，四舍五入的精度，也就是你想要保留几位小数。假设你想将 1.68 四舍五入至保留一位小数。那么，第一个输入是 1.68，第二个输入是 1。你可以用逗号将这两个输入分隔开。

不仅如此，只使用一个输入来调用 round() 函数也是完全可行的，就像这样。这一次，Python 识别出你没有指定第二个输入，于是，它自动选择将数字四舍五入到最接近的整数。

为了理解为什么这两种方法都有效，我们可以打开文档。你可以使用另一个函数 help() 来提供支持，就像这样。

我们可以看到，round() 确实接收了两个入参。
