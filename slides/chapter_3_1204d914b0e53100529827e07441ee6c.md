Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
Další vestavěnou funkcí je round. Přijímá dva vstupy: první je číslo, které chceš zaokrouhlit, a druhý je přesnost zaokrouhlení, tedy počet desetinných míst, která chceš zachovat. Řekněme, že chceš zaokrouhlit 1.68 na jedno desetinné místo. První vstup je 1.68, druhý vstup je 1. Vstupy se oddělují čárkou.

Ale je toho víc. Funkci round lze zavolat i s jediným vstupem, jako tady. Python v takovém případě zjistí, že druhý vstup nebyl zadán, a automaticky zaokrouhlí číslo na nejbližší celé číslo.

Abychom pochopili, proč oba přístupy fungují, podíváme se do dokumentace. To lze udělat pomocí další funkce – help – takto.

Ukáže se, že round přijímá dva vstupy.
