round(number, ndigits=None)

    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative.

`@script`
另一個內建函式是 round()。它接收兩個輸入：其一，你想要進行四捨五入的數字；其二，四捨五入的精度，也就是你想要保留幾位小數。假設你想將 1.68 四捨五入至保留一位小數。那麼，第一個輸入是 1.68，第二個輸入是 1。你可以用逗號將這兩個輸入分隔開。

不僅如此，只使用一個輸入來呼叫 round() 函式也是完全可行的，就像這樣。這一次，Python 識別出你沒有指定第二個輸入，於是，它自動選擇將數字四捨五入到最接近的整數。

為了理解為什麼這兩種方法都有效，我們可以開啟文件。你可以使用另一個函式 help() 來提供支援，就像這樣。

我們可以看到，round() 確實接收了兩個參數。
