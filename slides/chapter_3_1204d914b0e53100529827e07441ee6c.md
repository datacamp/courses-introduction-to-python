На самом деле функции для вас не совсем новая тема: вы уже ими пользовались. Например, type — это функция, которая возвращает тип значения. Но что такое функция? Если говорить просто, функция — это готовый фрагмент кода, предназначенный для решения определённой задачи. Вы можете вызывать функции, не написав при этом ни строчки кода самостоятельно. `@script`
Предположим, у вас есть список fam, который содержит только значения роста членов вашей семьи.

Допустим, вы хотите найти максимальное значение в этом списке. Вместо того чтобы писать собственный код на Python, который перебирает список и ищет наибольшее значение, можно воспользоваться встроенной функцией max. Это одна из встроенных функций Python, как и type. Просто передайте fam в функцию max в круглых скобках.

Результат вполне логичен: 1,89 — это наибольшее число в списке.

Функция max в данном случае сработала как закрытый механизм.

```{{3}}

```out
Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
Ещё одна встроенная функция — round. Она принимает два аргумента: первый — число, которое нужно округлить, второй — точность округления, то есть количество знаков после запятой. Допустим, вы хотите округлить 1,68 до одного знака после запятой. Первый аргумент — 1,68, второй — 1. Аргументы разделяются запятой.

Но есть и другой вариант. Функцию round вполне можно вызвать только с одним аргументом, вот так. В этом случае Python замечает, что второй аргумент не указан, и автоматически округляет число до ближайшего целого.

Чтобы понять, почему оба варианта работают, давайте откроем документацию. Это можно сделать с помощью ещё одной функции — help, вот так.

Из документации видно, что функция round принимает два аргумента.
