Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
另一個內建函式是 round()。它接受兩個輸入值：第一個是你想四捨五入的數字，第二個則是四捨五入的精確度，也就是小數點後要保留幾位數。假設你想將 1.68 四捨五入到小數點後一位。那麼，第一個輸入值就是 1.68，第二個輸入值則是 1，並用逗號將這兩個輸入值分隔開。

不僅如此，你也可以像這樣，只傳入一個輸入值來呼叫 round() 函式。這時，Python 會發現你沒有指定第二個輸入值，於是自動將數字四捨五入到最接近的整數。

想知道為什麼這兩種呼叫方式都行得通嗎？我們來查看說明文件。你可以使用另一個函式 help()，就像這樣。

從說明文件可以看出，round 接受兩個輸入值。
