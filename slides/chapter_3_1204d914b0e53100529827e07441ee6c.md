Help on built-in function round in module builtins:

round(number, ndigits=None)
    Round a number to a given precision in decimal digits.
    
    The return value is an integer if ndigits is omitted or None. 
    Otherwise the return value has the same type as the number. ndigits may be negative. 
```{{3}}

`@script`
Ще одна з таких вбудованих функцій — round. Вона приймає два вхідні значення. Перше — число, яке потрібно заокруглити. Друге — точність заокруглення, тобто скільки цифр після десяткової крапки зберегти. Скажімо, ви хочете заокруглити 1.68 до одного знака після крапки. Перше значення — 1.68, друге — 1. Вхідні значення відокремлюйте комою.

Але є й інший варіант. Можна викликати round лише з одним значенням, ось так. Цього разу Python розуміє, що другий аргумент не задано, і автоматично заокруглює число до найближчого цілого.

Щоб зрозуміти, чому працюють обидва підходи, відкриймо документацію. Це можна зробити ще однією функцією — help, ось так.

Виявляється, round приймає два значення.
