## การ slicing ใน list

```yaml
type: FullSlide
key: 125c4cb6c9
code_zoom: 70
```

`@part1`
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[3:5]
```{{1}}

```out
[1.68, 'mom']
```{{2}}

```py
fam[1:4]
```{{4}}

```out
[1.73, 'emma', 1.68]
```{{5}}

![ไวยากรณ์การ slicing ของ list ใน Python โดยค่า start จะถูกรวมไว้ใน subset แต่ค่า stop จะไม่ถูกรวม](https://assets.datacamp.com/img/translations/th-TH/production/repositories/288/datasets/83dd2f807be0d4d08a187935eed11667c18fcfe3/slicing-syntax.png = 40){{3}}

`@script`
ซึ่งช่วยให้เลือกสมาชิกหลายตัวพร้อมกันได้ ผลที่ได้คือ list ใหม่ วิธีทำคือระบุช่วงโดยใช้เครื่องหมายโคลอน มาดู list อีกครั้ง แล้วลองรันโค้ดชิ้นนี้กัน

ลองเดาดูว่าจะได้ผลลัพธ์อะไร อาจเป็น list ที่มีค่า 1.68 ข้อความ "mom" และค่า 1.71 ซึ่งตรงกับสมาชิกตัวที่ 4, 5 และ 6 ของ list ใช่ไหม มาดูผลลัพธ์จริงกัน

ปรากฏว่าได้เฉพาะสมาชิกที่มี index 3 และ 4 เท่านั้น สมาชิกที่มี index 5 ไม่ถูกรวมไว้ด้วย หลักการทั่วไปคือ index ที่ระบุก่อนโคลอน หรือจุดเริ่มต้นของ slice จะถูกรวมไว้ แต่ index ที่ระบุหลังโคลอน หรือจุดสิ้นสุดของ slice จะไม่ถูกรวมไว้

เมื่อเข้าใจหลักการนี้แล้ว ลองเดาดูว่าคำสั่งนี้จะคืนค่าอะไร

น่าจะเดาถูกว่าคำสั่งนี้ให้ list ที่มี 3 สมาชิก ตรงกับสมาชิกที่มี index 1, 2 และ 3 ของ list fam

นอกจากนี้ยังเลือกที่จะละ index ก่อนหรือหลังโคลอนได้ด้วย

`@script`
ถ้าละ index จุดเริ่มต้นของ slice Python จะเริ่มนับจาก index 0 โดยอัตโนมัติ เหมือนตัวอย่างนี้

ถ้าละ index จุดสิ้นสุดของ slice จะได้สมาชิกทุกตัวตั้งแต่จุดนั้นจนถึงตัวสุดท้ายของ list เหมือนที่เห็นในตัวอย่างนี้
