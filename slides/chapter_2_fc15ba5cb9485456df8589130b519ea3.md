```{{2}}

```{{4}}

```out

```{{5}}

![La sintaxis de slicing para listas de Python, que muestra que el valor inicial se incluye en el subconjunto, mientras que el valor final se excluye.](https://assets.datacamp.com/img/translations/es-ES/q1/production/repositories/288/datasets/83dd2f807be0d4d08a187935eed11667c18fcfe3/slicing-syntax.png = 40){{3}}

`@script`
La segmentación te permite seleccionar varios elementos de una lista para crear otra nueva. Para ello, puedes especificar un rango utilizando dos puntos. Echemos otro vistazo a la lista y, a continuación, probemos este fragmento de código.

¿Puedes adivinar qué te devolverá? ¿Una lista con el decimal 1,68, la cadena mom y el decimal 1,71, correspondientes al cuarto, quinto y sexto elemento de la lista, tal vez? Veamos cuál es el resultado.

Aparentemente, solo se devuelven los elementos con índice 3 y 4. El elemento con índice 5 no está incluido. Por lo general, esta es la sintaxis: se incluye el índice que especificas antes de los dos puntos (es decir, donde comienza la segmentación) pero no se incluye que el índice que especificas después de los dos puntos (es decir, donde termina la segmentación).

Teniendo esto en cuenta, ¿puedes decir qué devolverá esta llamada?

Probablemente hayas adivinado correctamente que esta llamada te da una lista con tres elementos, correspondientes a los elementos con índice 1, 2 y 3 de la lista fam.

También puedes omitir el índice antes o después de los dos puntos.
