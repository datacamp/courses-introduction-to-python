```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]

```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[7] = 1.86
fam
```{{1}}

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{1}}

```py
fam[0:2] = ["lisa", 1.74]
fam
```{{2}}

```out
['lisa', 1.74, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{2}}

`@script`
Modifier des éléments d'une liste est assez simple. Vous utilisez les mêmes crochets que nous avons utilisés pour créer des sous-ensembles, puis vous attribuez de nouveaux éléments avec le signe égal. Supposons qu'en regardant de nouveau fam, vous réalisiez que la taille de votre père n'est plus à jour, puisqu'il rapetisse avec l'âge. Au lieu de un-virgule-quatre-vingt-neuf mètre, ce devrait être un-virgule-quatre-vingt-six mètre. Pour modifier cet élément de liste, qui est à l'indice sept, vous pouvez utiliser cette ligne de code.

Si vous vérifiez maintenant fam, vous verrez que la valeur a été mise à jour.

Vous pouvez même changer tout un segment de liste d'un coup. Pour modifier les éléments "liz" et un-virgule-soixante-treize, vous accédez aux deux premiers éléments avec zéro:deux, puis vous leur attribuez une nouvelle liste.

Vous souvenez-vous encore en quoi l'opérateur plus différait pour les chaînes de caractères et les entiers?

Eh bien, c'est encore différent pour les listes. Si vous utilisez le signe plus avec deux listes, Python colle simplement leurs contenus dans une seule liste. Supposons que vous vouliez ajouter votre propre nom et votre taille à la liste des tailles fam. Ceci fera l'affaire.

Bien sûr, vous pouvez aussi stocker cette nouvelle liste dans une variable, fam_ext par exemple.

Enfin, supprimer des éléments d'une liste est aussi très simple, il faut utiliser del ici. Prenez cette ligne, par exemple, qui supprime l'élément à l'indice deux, donc "emma", de la liste.

Si vous vérifiez maintenant fam, vous verrez que la chaîne "emma" a disparu. Comme vous avez retiré un indice, tous les éléments qui suivaient "emma" ont glissé d'un indice. Si vous exécutez de nouveau la même ligne, vous retirez encore l'élément à l'indice deux, qui est maintenant la taille d'emma, un-virgule-soixante-huit mètre.
