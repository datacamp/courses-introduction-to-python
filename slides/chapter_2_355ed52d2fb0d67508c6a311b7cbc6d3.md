## 更改串列元素

```yaml
type: FullSlide
key: c1d58a3c4c
code_zoom: 64
```

`@part1`
```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[7] = 1.86
fam
```{{1}}

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{1}}

```py
fam[0:2] = ["lisa", 1.74]
fam
```{{2}}

```out
['lisa', 1.74, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{2}}

`@script`
更改串列裡的元素非常簡單。使用先前選取串列元素時用到的方括號，來選取目標，再用等號指派新的元素值。假設在重新檢查 fam 串列時，你發現爸爸的身高資料過時了，畢竟人年紀大了都會有點縮水，因此，你需要把他的身高從 1.89 公尺改成 1.86 公尺。那麼，要修改索引為 7 的元素，只需這行程式碼就能實現。

此時再查看 fam，就會發現值已經更新。

你甚至能一次更改整個切片。比如，你想更改 "liz" 和 1.73，用 0:2 選取前兩個元素，再將新的串列指派給這個切片。

對了，你還記得對字串和整數使用加號有什麼區別嗎？

```{{1}}

```py

```{{2}}
```py
del fam[2]
```{{3}}
```py
fam
```{{4}}

```out
['lisa', 1.74, 1.68, 'mom', 1.71, 'dad', 1.86]
```{{4}}

`@script`
串列的加號的作用又不同。如果使用加號連接兩個串列，Python 會將它們的內容串接成一個串列。比如你想把自己的名字和身高也加進 fam 串列裡，這麼寫就能實現。

當然，你也可以使用變數來儲存這個新串列，比如 fam_ext。

刪掉串列裡的元素同樣簡單，使用 del 指令就行。比如這行程式碼，刪除了索引為 2 的元素，也就是 "emma"。

再次查看 fam，字串 "emma" 已經消失了。因為刪除了一個索引位置，原本位於 "emma" 後面的所有元素，都會自動向前挪一位。要是你再執行一次相同的程式碼，刪掉的依然是索引 2 位置上的元素，這次對應的就是 emma 的身高 1.68 公尺了。

這是因為用等號將 x 指派給 y 時，
