## Изменение элементов списка

```yaml
type: FullSlide
key: c1d58a3c4c
code_zoom: 64
```

`@part1`
```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[7] = 1.86
fam
```{{1}}

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{1}}

```py
fam[0:2] = ["lisa", 1.74]
fam
```{{2}}

```out
['lisa', 1.74, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{2}}

`@script`
Изменить элемент списка несложно. Используйте те же квадратные скобки, что и при срезах, и присвойте новое значение с помощью знака равенства. Допустим, вы снова посмотрели на список fam и заметили, что рост отца уже неактуален: с возрастом он немного уменьшился. Вместо 1,89 метра должно быть 1,86. Этот элемент находится под индексом 7, и вот строка кода, которая его обновит.

Если теперь вывести fam, вы увидите обновлённое значение.

Можно также изменить сразу целый срез списка. Чтобы заменить элементы «liz» и 1,73, обратитесь к первым двум элементам через срез 0:2 и присвойте им новый список.

Помните, как оператор «плюс» по-разному работал со строками и целыми числами?

## Добавление и удаление элементов

```yaml

```py

```{{1}}

```out

```{{1}}

```py
fam_ext = fam + ["me", 1.79]
```{{2}}
```py
del fam[2]
```{{3}}
```py
fam
```{{4}}

```out
['lisa', 1.74, 1.68, 'mom', 1.71, 'dad', 1.86]
```{{4}}

`@script`
Со списками он снова ведёт себя иначе. Если применить знак «плюс» к двум спискам, Python просто объединит их содержимое в один список. Допустим, вы хотите добавить в список fam своё имя и рост. Вот как это сделать.

Конечно, новый список можно сохранить в переменную, например fam_ext.

Наконец, удалить элементы из списка тоже просто: для этого используется команда del. Например, вот эта строка удаляет элемент с индексом 2, то есть строку «emma».

Если теперь вывести fam, строки «emma» уже не будет. После удаления элемента все следующие за ним сдвинулись на один индекс влево. Если выполнить ту же строку повторно, будет удалён элемент с индексом 2, которым теперь является рост Эммы — 1,68 метра.

Теперь важно разобраться, как списки Python устроены
