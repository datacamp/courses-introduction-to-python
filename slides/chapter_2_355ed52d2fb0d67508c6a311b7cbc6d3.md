## 更改串列元素

```yaml
type: FullSlide
key: c1d58a3c4c
code_zoom: 64
```

`@part1`
```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[7] = 1.86
fam
```{{1}}

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{1}}

```py
fam[0:2] = ["lisa", 1.74]
fam
```{{2}}

```out
['lisa', 1.74, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{2}}

`@script`
修改串列裡的元素非常簡單。用之前提取子集時用到的方括號選中目標，再用等號賦一個新值就完成了。假設在重新檢查 fam 串列時，你發現爸爸的身高資料過時了，畢竟人年紀大了都會「有點縮水」，因此，你需要把他的身高從 1.89 米改成 1.86 米。那麼，要修改索引為 7 的這個元素，只需這行程式碼就能實現。

此時再列印 fam，數值就已經更新了。

你甚至能一次性替換一整段切片。比如，你想把 "liz" 和 1.73 一起改掉，用 0:2 選中前兩個元素，然後直接賦給它一個新的串列。

對了，你還記得對字串和整數使用加號有什麼區別嗎？

```{{2}}

```{{3}}
```py
fam
```{{4}}

```out
['lisa', 1.74, 1.68, 'mom', 1.71, 'dad', 1.86]
```{{4}}

`@script`
對於串列，它的作用又是不同的。如果你把兩個串列加在一起，Python 會直接把它們的內容拼接成一個大串列。比如你想把自己的名字和身高也加進 fam 串列裡，這麼寫就能實現。

當然，你也可以把這個新串列存進一個變數裡，比如 fam_ext。

最後，刪掉串列裡的元素同樣簡單，用 del 關鍵字就行。比如這行程式碼刪除了索引為 2 的元素，也就是 "emma"。

再看一下 fam，字串 "emma" 就已經徹底消失了。因為刪掉了一個位置，排在 "emma" 後面的所有元素都會自動向前挪一位。要是你再執行一次完全相同的程式碼，刪掉的依然是索引 2 位置上的元素，不過這次對應的就是 emma 的身高 1.68 米了。

假設我們直接用等號，把串列 x 賦值給一個新變數 y。

神奇的事情發生了。如果你再去列印 x，會發現 x 裡的第二個元素竟然也跟著一起變了！

這是因為用等號把 x 賦值給 y 時，
