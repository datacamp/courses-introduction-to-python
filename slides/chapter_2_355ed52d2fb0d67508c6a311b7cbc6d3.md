`@part1`
```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam[7] = 1.86
fam
```{{1}}

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{1}}

```py
fam[0:2] = ["lisa", 1.74]
fam
```{{2}}

```out
['lisa', 1.74, 'emma', 1.68, 'mom', 1.71, 'dad', 1.86]
```{{2}}

`@script`
การเปลี่ยนค่าสมาชิกในลิสต์ทำได้ไม่ยาก ใช้วงเล็บเหลี่ยมเหมือนตอน subset แล้วกำหนดค่าใหม่ด้วยเครื่องหมายเท่ากับ สมมติว่าดูลิสต์ fam แล้วพบว่าส่วนสูงของพ่อไม่ถูกต้องแล้ว เพราะอายุมากขึ้นส่วนสูงก็ลดลง จาก 1.89 เมตร ต้องเป็น 1.86 เมตร สมาชิกตัวนี้อยู่ที่ index 7 ก็ใช้โค้ดบรรทัดนี้เพื่อแก้ไขได้เลย

ลองเรียกดู fam อีกครั้ง ค่าจะอัปเดตแล้ว

นอกจากนี้ยังเปลี่ยนค่าทีละหลายสมาชิกพร้อมกันได้ด้วย เช่น ถ้าต้องการเปลี่ยน "liz" และ 1.73 ก็ใช้ 0:2 เพื่อเข้าถึงสมาชิกสองตัวแรก แล้วกำหนดลิสต์ใหม่ให้เลย

ยังจำได้ไหมว่าเครื่องหมายบวกทำงานต่างกันอย่างไรกับ string และ integer?

## การเพิ่มและลบสมาชิก

```yaml
type: FullSlide

`@part1`
```py
fam + ["me", 1.79]
```{{1}}

```out
['lisa', 1.74,'emma', 1.68, 'mom', 1.71, 'dad', 1.86, 'me', 1.79]
```{{1}}

```py
fam_ext = fam + ["me", 1.79]
```{{2}}
```py
del fam[2]
```{{3}}
```py
fam
```{{4}}

```out
['lisa', 1.74, 1.68, 'mom', 1.71, 'dad', 1.86]
```{{4}}

`@script`
กับลิสต์ก็ต่างกันเช่นกัน ถ้าใช้เครื่องหมายบวกกับลิสต์สองตัว Python จะนำเนื้อหาของทั้งสองมารวมกันเป็นลิสต์เดียว สมมติต้องการเพิ่มชื่อและส่วนสูงของตัวเองเข้าไปในลิสต์ fam ก็ใช้วิธีนี้ได้เลย

แน่นอนว่าเก็บลิสต์ใหม่นี้ไว้ในตัวแปรก็ได้ เช่น fam_ext

สุดท้าย การลบสมาชิกออกจากลิสต์ก็ทำได้ง่ายเช่นกัน ใช้คำสั่ง del ตัวอย่างเช่น บรรทัดนี้ลบสมาชิกที่ index 2 ซึ่งก็คือ "emma" ออกจากลิสต์

ลองเรียกดู fam อีกครั้ง จะเห็นว่า "emma" หายไปแล้ว และเนื่องจาก index เลื่อนใหม่ ถ้ารันบรรทัดเดิมอีกครั้ง ตัวที่ถูกลบจะเป็น index 2 ตัวใหม่ ซึ่งก็คือส่วนสูงของ emma คือ 1.68 เมตร

ทีนี้มาทำความเข้าใจกันว่า Python ทำงานกับลิสต์อย่างไร

`@script`
ว่าลิสต์อยู่ที่ไหนในหน่วยความจำ ไว้ใน x นั่นหมายความว่า x ไม่ได้เก็บค่าสมาชิกโดยตรง แต่เก็บ reference หรือตัวชี้ไปยังลิสต์นั้น สำหรับการใช้งานทั่วไปความแตกต่างนี้ไม่สำคัญมาก แต่จะสำคัญขึ้นมากเมื่อเริ่มคัดลอกลิสต์ มาดูตัวอย่างกัน

ลองเก็บลิสต์ x ไว้ในตัวแปรใหม่ชื่อ y โดยใช้เครื่องหมายเท่ากับ

จากนั้นลองเปลี่ยนสมาชิกที่ index 1 ในลิสต์ y แบบนี้

สิ่งที่น่าแปลกใจคือถ้าเรียกดู x อีกครั้ง สมาชิกตัวที่สองของ x ก็เปลี่ยนไปด้วย

เพราะตอนที่คัดลอก x ไปยัง y ด้วยเครื่องหมายเท่ากับ
