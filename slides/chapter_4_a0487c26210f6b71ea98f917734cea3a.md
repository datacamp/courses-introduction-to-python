`@script`
Python सेशन में वाकई NumPy यूज़ करने के लिए, आप numpy पैकेज को ऐसे इम्पोर्ट कर सकते हैं।

चलिए numpy array बनाकर शुरू करते हैं। यह आप NumPy के array फंक्शन से करते हैं। इनपुट में एक रेगुलर Python list होती है। मैं यहाँ array को दो बार यूज़ कर रहा हूँ, ताकि पहले वाली height और weight लिस्ट्स के NumPy वर्ज़न बना लूँ। np_height और np_weight।

आइए एक ही कॉल से सबका BMI फिर से निकालकर देखें।

इस बार सब ठीक चला। कैलकुलेशन एलिमेंट-वाइज़ हो गए। पहले व्यक्ति का BMI निकला, np_weight के पहले एलिमेंट को np_height के पहले एलिमेंट के स्क्वेयर से भाग देकर। दूसरे व्यक्ति का BMI दूसरे height और weight से निकला, और ऐसे ही आगे।

दूसरा, यह जानना ज़रूरी है कि NumPy array, Python का एक नया टाइप ही है, ठीक वैसे जैसे float, string और list। इसका मतलब है कि इसके अपने methods होते हैं, जिनका बर्ताव कभी-कभी आपकी उम्मीद से अलग हो सकता है।

```{{3}}

```{{4}}

```out

```{{4}}

`@script`
आप NumPy arrays को लगभग वैसे ही यूज़ कर सकते हैं जैसे रेगुलर Python लिस्ट्स को। मान लीजिए आप अपने array से कोई एलिमेंट निकालना चाहते हैं, तो स्क्वेयर ब्रैकेट्स इस्तेमाल कीजिए। मान लीजिए आप दूसरे व्यक्ति का bmi लेना चाहते हैं, यानी इंडेक्स 1। यह तरीके से हो जाएगा।

खासतौर पर NumPy में, लिस्ट सबसेटिंग का एक और तरीका है। बूलियन की array का इस्तेमाल। मान लीजिए आप bmi array में वे सारे BMI लेना चाहते हैं जो 23 से ऊपर हैं। पहला कदम है ग्रेटर-देअन वाला साइन लगाना, यूँ।

रिज़ल्ट एक NumPy array होगा जिसमें बूलियन वैल्यूज़ होंगी। True जब संबंधित bmi, 23 से ऊपर होगा, और False जब नीचे होगा। इसके बाद, आप इस बूलियन array को स्क्वेयर ब्रैकेट्स में डालकर सबसेटिंग कर सकते हैं। केवल वे एलिमेंट चुने जाएँगे जो 23 से ऊपर हैं, यानी जिनके लिए संबंधित बूलियन True है। यहाँ सिर्फ़ एक BMI, 23 से ऊपर है, तो हमें उसी एक वैल्यू वाला NumPy array मिलता है, वही ख़ास BMI।

कंपेरिज़न के नतीजों का इस्तेमाल करके डेटा से चयन करना, इनसाइट्स पाने का बहुत आम और असरदार तरीका है।
