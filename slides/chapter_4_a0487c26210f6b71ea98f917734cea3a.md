что список в Python весьма мощный инструмент. Он может хранить данные любого типа, причём разные типы одновременно. Элементы можно изменять, добавлять и удалять. Когда вы работаете с данными, часто приходится выполнять операции сразу над целыми наборами значений, и делать это быстро. Со списками это становится проблемой.

Если теперь вы захотите рассчитать индекс массы тела для каждого члена семьи, логично было бы предположить, что вычисления выполнятся поэлементно.

Однако Python выдаёт ошибку, потому что он не умеет выполнять математические операции над списками. Можно решить это, перебирая элементы по одному и вычисляя индекс массы тела для каждого человека отдельно. Но такой подход крайне неэффективен и утомителен.

Он очень похож на список, но с одним важным дополнением: над массивами можно выполнять вычисления целиком. Это просто и при этом очень быстро.

## Сравнение

```yaml

`@part1`
```py
height = [1.73, 1.68, 1.71, 1.89, 1.79]
weight = [65.4, 59.2, 63.6, 88.4, 68.7]
weight / height ** 2
```{{1}}

```out
TypeError: unsupported operand type(s) for ** or pow(): 'list' and 'int'
```{{1}}

```py
np_height = np.array(height)
np_weight = np.array(weight)
np_weight / np_height ** 2
```{{2}}

```out
array([21.85171573, 20.97505669, 21.75028214, 24.7473475 , 21.44127836])
```{{2}}

`@script`
Давайте сравним оба подхода. Сначала мы пытались выполнить вычисления с обычными списками, но получили ошибку, потому что Python не умеет работать со списками так, как нам нужно. Затем мы преобразовали эти списки в массивы NumPy. Те же операции теперь работают без каких-либо проблем. NumPy умеет обращаться с массивами как с отдельными значениями, и это очень удобно.

## NumPy: особенности

```yaml

`@part1`
```py
np.array([1.0, "is", True])
```{{1}}

```out
array(['1.0', 'is', 'True'], dtype='<U32')
```{{1}}

- Массивы NumPy содержат только один тип{{1}}

`@script`
Тем не менее стоит быть внимательными. Во-первых, NumPy так легко выполняет все эти операции, потому что предполагает: массив содержит значения только одного типа. Это может быть массив вещественных чисел, массив булевых значений и так далее. Если попытаться создать массив из значений разных типов, NumPy приведёт все элементы к единому типу. В данном примере это строка: булево значение и вещественное число были преобразованы в строки.

Во-вторых, массив NumPy — это самостоятельный тип данных в Python, наряду с числами, строками и списками. Это значит, что у него есть собственные методы, которые могут работать иначе, чем вы ожидаете.

`@script`
с массивами NumPy можно работать почти так же, как с обычными списками Python. Чтобы получить элементы массива, используйте квадратные скобки. Например, чтобы узнать индекс массы тела второго человека, то есть элемент с индексом 1, достаточно такого обращения.

Для массивов NumPy есть ещё один способ выборки элементов — с помощью массива булевых значений. Предположим, вы хотите получить все значения индекса массы тела из массива bmi, которые превышают 23. Сначала используйте знак «больше», вот так.

Результат — массив NumPy из булевых значений. Значение True означает, что соответствующий индекс массы тела выше 23, False — что ниже. Затем используйте этот булев массив внутри квадратных скобок для выборки. Будут выбраны только те элементы массива bmi, для которых значение равно True, то есть выше 23. В нашем примере такое значение одно, поэтому результат — массив NumPy с одним элементом.

Использование результата сравнения для отбора данных — очень распространённый приём, который позволяет находить неожиданные закономерности.
