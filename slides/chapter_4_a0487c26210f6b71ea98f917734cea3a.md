## NumPy：注意事项

```yaml

```py
np.array([1.0, "is", True])
```{{1}}

```out
array(['1.0', 'is', 'True'], dtype='<U32')
```{{1}}

- NumPy 数组：仅包含一种类型{{1}}

`@script`
不过，你仍需要留心。首先，NumPy 能够如此轻松地完成这一切，是因为它假设你的 NumPy 数组只能包含单一类型的值。它要么是一个全由浮点数组成的数组，要么是一个全由布尔值组成的数组，以此类推。如果你非要尝试创建一个包含不同类型数据的数组，例如这样，最终得到的 NumPy 数组将只包含一种单一类型，在当前示例中为字符串。布尔值和浮点数都被转换成了字符串。

其次，你要了解，NumPy 数组只是一种新的 Python 数据类型，就像之前的浮点数、字符串和列表类型一样。这意味着它拥有自己专属的方法，并且这些方法的行为表现可能与你的预想有所不同。

```{{4}}

```out

```{{4}}

`@script`
你可以像使用普通 Python 列表一样使用 NumPy 数组。例如，当你想从数组中获取元素时，可以使用方括号。假设你想获取第二个人的 BMI，即索引为 1 的位置，这样做就能达到目的。

特别地，对于 NumPy 而言，还有另一种进行列表子集提取的方法：使用布尔值数组。假设你想从 bmi 数组中获取所有大于 23 的 BMI 值。第一步是使用大于号，就像这样：

结果是一个包含布尔值的 NumPy 数组：如果对应的 BMI 高于 23，则为 True；如果小于或等于 23，则为 False。接着，你可以将这个布尔值数组放在方括号内来进行子集提取。只有 bmi 中大于 23 的元素会被选中，也就是那些对应的布尔值为 True 的元素。由于只有一个 BMI 值高于 23，所以我们最终得到的是一个仅包含单个值的 NumPy 数组，它就是那个特定 BMI 值。

利用比较运算的结果来进行数据筛选，是数据分析中极其常用且往往能发现意外洞察的好方法。
