## NumPy：注意事項

```yaml
type: FullSlide
key: f9882b091b
code_zoom: 90
```

`@part1`
```py
np.array([1.0, "is", True])
```{{1}}

```out
array(['1.0', 'is', 'True'], dtype='<U32')
```{{1}}

- NumPy 陣列：僅包含一種型別{{1}}

`@script`
不過，你仍需要留心。首先，NumPy 能夠如此輕鬆地完成這一切，是因為它假設你的 NumPy 陣列只能包含單一類型的值。它要麼是一個全由浮點數組成的陣列，要麼是一個全由布林值組成的陣列，以此類推。如果你非要嘗試建立一個包含不同類型資料的陣列，例如這樣，最終得到的 NumPy 陣列將只包含一種單一類型，在目前範例中為字串。布林值和浮點數都被轉換成了字串。

其次，你要了解，NumPy 陣列只是一種新的 Python 資料型別，就像之前的浮點數、字串和串列類型一樣。這意味著它擁有自己專屬的方法，並且這些方法的行為表現可能與你的預想有所不同。

`@script`
你可以像使用普通 Python 串列一樣使用 NumPy 陣列。例如，當你想從陣列中獲取元素時，可以使用方括號。假設你想獲取第二個人的 BMI，即索引為 1 的位置，這樣做就能達到目的。

特別地，對於 NumPy 而言，還有另一種進行串列子集提取的方法：使用布林值陣列。假設你想從 bmi 陣列中獲取所有大於 23 的 BMI 值。第一步是使用大於號，就像這樣：

結果是一個包含布林值的 NumPy 陣列：如果對應的 BMI 高於 23，則為 True；如果小於或等於 23，則為 False。接著，你可以將這個布林值陣列放在方括號內來進行子集提取。只有 bmi 中大於 23 的元素會被選中，也就是那些對應的布林值為 True 的元素。由於只有一個 BMI 值高於 23，所以我們最終得到的是一個僅包含單個值的 NumPy 陣列，它就是那個特定 BMI 值。

利用比較運算的結果來進行資料篩選，是資料分析中極其常用且往往能發現意外洞察的好方法。
