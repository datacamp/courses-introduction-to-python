`@script`
要在 Python 工作階段中實際使用 NumPy，你可以像這樣匯入 numpy 套件。

我們先建立一個 NumPy 陣列。你可以使用 NumPy 的 array() 函式來建立陣列，只需要輸入一個一般 Python 串列。我在這裡使用了兩次 array()，將先前的 height 和 weight 串列轉換成 NumPy 陣列：np_height 與 np_weight。

我們再次嘗試透過單次呼叫來計算每個人的 BMI。

這次成功了：計算是以逐元素的方式進行的。使用 np_weight 的第一個元素除以 np_height 中第一個元素的平方，計算出第一個人的 BMI；再用兩者的第二個元素計算出第二個人的 BMI，以此類推。

## NumPy：注意事項

```yaml
type: FullSlide
key: f9882b091b
code_zoom: 90
```

`@part1`
```py
np.array([1.0, "is", True])
```{{1}}

```out
array(['1.0', 'is', 'True'], dtype='<U32')
```{{1}}

- NumPy 陣列：僅包含一種型別{{1}}

`@script`
不過，你仍需要留心。首先，NumPy 能夠如此輕鬆地完成這些運算，是因為 NumPy 陣列只能包含單一資料型別的值，例如全由浮點數組成的陣列，或是全由布林值組成的陣列，以此類推。如果你試著建立一個包含不同資料型別的陣列，例如這樣，最後得到的 NumPy 陣列仍然只會包含單一型別，在目前範例中為字串，原本的布林值和浮點數都被轉換成了字串。

其次，你需要知道，NumPy 陣列其實就是另一種 Python 資料型別，就像浮點數、字串和串列一樣。這表示它也有自己的方法，並且這些方法的行為可能與你預期的不同。

在使用不同的 Python 資料型別進行操作時，請務必留心，因為結果可能會相差甚遠！

## 選取 NumPy 陣列元素

```out

```{{2}}

```out

```{{2}}

```py

```{{3}}

```out
array([False, False, False,  True, False])
```{{3}}

```py
bmi[bmi > 23]
```{{4}}

```out
array([24.7473475])
```{{4}}

`@script`
你可以像使用一般 Python 串列一樣使用 NumPy 陣列。例如，當你想取得陣列中元素時，可以使用方括號。假設你想取得第二個人的 BMI，即索引為 1 的元素，這樣就能做到。

另外，NumPy 還有另一種選取陣列元素的方式，就是使用布林值陣列。假設你想從 bmi 陣列中選取所有大於 23 的 BMI 值。第一步是使用大於符號，就像這樣：

得到的結果是一個包含布林值的 NumPy 陣列：如果對應的 BMI 大於 23，則為 True；如果小於或等於 23，則為 False。接著，你可以將這個布林值陣列放在方括號內，用來選取元素。這樣就只會選取 bmi 陣列中大於 23 的元素，也就是對應布林值為 True 的元素。由於只有一個 BMI 值大於 23，所以我們最終得到的是一個僅包含單個值的 NumPy 陣列，它就是符合條件的 BMI 值。

利用比較運算的結果來選取資料，是資料分析中非常常見的方法，且往往能發現意外洞察。
