Apoi, acele liste au fost convertite în array-uri NumPy. Aceleași operații funcționează acum fără nicio problemă. NumPy știe să trateze un array ca pe o valoare unitară, ceea ce e cu adevărat util.

np.array([1.0, "is", True])

- Array-urile NumPy: conțin un singur tip{{1}}

`@script`
Totuși, trebuie să fii atent la câteva lucruri. În primul rând, NumPy funcționează atât de eficient pentru că presupune că un array conține valori de un singur tip. Fie e un array de numere reale, fie de valori booleene, și tot așa. Dacă încerci să creezi un array cu tipuri diferite, de exemplu, array-ul NumPy rezultat va conține un singur tip, în acest caz șiruri de caractere. Valoarea booleană și numărul real vor fi ambele convertite la șiruri de caractere.

În al doilea rând, un array NumPy este pur și simplu un nou tip Python, la fel ca numerele reale, șirurile de caractere sau listele. Asta înseamnă că vine cu propriile metode, care se pot comporta diferit față de ce te-ai aștepta.

## Indexare în NumPy

```yaml
type: FullSlide
key: c1f3774f83
code_zoom: 71
```

`@part1`
```py
bmi
```{{1}}

```out
array([21.85171573, 20.97505669, 21.75028214, 24.7473475 , 21.44127836])
```{{1}}

```py
bmi[1]
```{{2}}

```out
20.975
```{{2}}

```py
bmi > 23
```{{3}}

```out
array([False, False, False,  True, False])
```{{3}}

```py
bmi[bmi > 23]
```{{4}}

```out
array([24.7473475])
```{{4}}

`@script`
poți lucra cu array-uri NumPy aproape la fel ca cu listele Python obișnuite. Când vrei să accesezi elemente din array, poți folosi parantezele pătrate. Să zicem că vrei IMC-ul celei de-a doua persoane, deci elementul de la indexul 1. Asta e tot ce ai nevoie.

Specific pentru NumPy, mai există și o altă metodă de selecție: folosind un array de valori booleene. Să zicem că vrei toate valorile IMC din array-ul bmi care sunt peste 23. Primul pas este să folosești operatorul mai mare decât, astfel.

Rezultatul este un array NumPy de valori booleene: True dacă IMC-ul corespunzător este peste 23, False dacă este sub. Apoi, poți folosi acest array de valori booleene între paranteze pătrate pentru a face selecția. Sunt selectate doar elementele din bmi pentru care valoarea booleană corespunzătoare este True, adică valorile peste 23. Există un singur IMC peste 23, deci obținem un array NumPy cu o singură valoare, acel IMC specific.

Folosirea rezultatului unei comparații pentru a selecta date este o metodă foarte frecventă de a descoperi informații neașteptate.
