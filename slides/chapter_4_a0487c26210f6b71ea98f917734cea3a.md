`@script`

อีกเรื่องที่ควรรู้คือ NumPy array เป็นประเภทข้อมูลใหม่ใน Python เหมือนกับ float, string หรือ list ดังนั้นมันจึงมี method เป็นของตัวเอง ซึ่งอาจทำงานต่างจากที่คาดไว้

`@script`
การใช้งาน NumPy array ส่วนใหญ่ก็คล้ายกับ list แบบปกติ เช่น ถ้าต้องการดึงสมาชิกออกมา ก็ใช้วงเล็บเหลี่ยมได้เลย อยากได้ค่าดัชนีมวลกายของคนที่สอง ซึ่งอยู่ที่ index 1 ก็ทำแบบนี้

สำหรับ NumPy โดยเฉพาะ ยังมีวิธีเลือกข้อมูลอีกแบบหนึ่ง คือใช้ array ของค่า boolean สมมติอยากได้ค่าดัชนีมวลกายทุกค่าใน array ที่มากกว่า 23 ขั้นแรกใช้เครื่องหมายมากกว่าแบบนี้

ผลลัพธ์คือ NumPy array ที่มีค่า boolean ค่าใดที่มากกว่า 23 จะได้ True ค่าใดที่น้อยกว่าจะได้ False จากนั้นนำ array ของ boolean นี้ใส่ในวงเล็บเหลี่ยมเพื่อเลือกข้อมูล จะได้เฉพาะค่าที่ตำแหน่งนั้นเป็น True เท่านั้น มีค่าดัชนีมวลกายเพียงค่าเดียวที่มากกว่า 23 จึงได้ผลลัพธ์เป็น NumPy array ที่มีค่าเดียว

การใช้ผลลัพธ์จากการเปรียบเทียบมาคัดกรองข้อมูลแบบนี้ เป็นวิธีที่ใช้กันบ่อยมากและให้ข้อมูลเชิงลึกที่น่าสนใจ
