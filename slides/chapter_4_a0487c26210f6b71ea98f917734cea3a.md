`@script`

다음으로, NumPy 배열은 이전에 다뤘던 실수형, 문자열, 리스트 타입처럼 단순히 새로운 종류의 Python 타입이라는 점을 알아두어야 합니다. 다시 말하면, 자체 메서드를 가지므로 예상과 다르게 동작할 수 있다는 거죠.

## NumPy 부분 추출

```yaml
type: FullSlide
key: c1f3774f83
code_zoom: 71
```

`@part1`
```py
bmi
```{{1}}

```out
array([21.85171573, 20.97505669, 21.75028214, 24.7473475 , 21.44127836])
```{{1}}

```py
bmi[1]
```{{2}}

```out
20.975
```{{2}}

```py
bmi > 23
```{{3}}

```out
array([False, False, False,  True, False])
```{{3}}

```py
bmi[bmi > 23]
```{{4}}

```out
array([24.7473475])
```{{4}}

`@script`
NumPy 배열은 기존 Python 리스트와 거의 동일하게 사용할 수 있습니다. 예를 들어, 배열에서 요소를 가져오고 싶을 때는 대괄호를 사용할 수 있습니다. 두 번째 사람의 BMI를 구한다고 가정해보겠습니다. 인덱스 1에 해당하겠죠. 이렇게 할 수 있습니다.

특히 NumPy의 경우, 리스트를 부분 추출하는 또 다른 방법이 있습니다. 불리언 배열을 사용하는 것입니다. 예를 들어, bmi 배열에서 23을 초과하는 모든 BMI 값을 얻고 싶다면, 먼저, 이렇게 부등호를 사용합니다.

결과는 불리언을 포함하는 NumPy 배열입니다. bmi 값이 23보다 크면 True, 작으면 False입니다. 다음으로, 이 불리언 배열을 대괄호 안에 넣어 부분 추출을 할 수 있습니다. 23을 초과하는 bmi 요소, 즉 불리언 값이 True인 요소만 선택됩니다. 23을 초과하는 BMI는 하나뿐이므로, 결과적으로 해당 BMI 하나만 포함된 NumPy 배열이 생성됩니다.

비교 결과를 사용하여 데이터를 선택하는 건 놀라운 인사이트를 얻기 위해 흔히 사용하는 방법입니다.
