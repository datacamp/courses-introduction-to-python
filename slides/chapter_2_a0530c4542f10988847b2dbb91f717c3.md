## Python 串列

```yaml
type: FullSlide
key: e0a7e67ef6
code_zoom: 66
```

`@part1`
- `[a, b, c]`


```py
[1.73, 1.68, 1.71, 1.89]
```{{1}}

```out
[1.73, 1.68, 1.71, 1.89]
```{{1}}

```py
fam = [1.73, 1.68, 1.71, 1.89]
fam
```{{2}}

```out
[1.73, 1.68, 1.71, 1.89]
```{{2}}

- 為數值集合命名{{3}}

- 包含任意類型{{4}}

- 包含不同類型{{5}}

`@script`
你可以用方括號來建立這樣的串列。假設你向兩位姐妹和父母詢問了他們的身高，單位是米。串列可以這樣建。

當然，這個資料結構也可以用變數名來引用。只要把變數名和等號放在前面，就像這裡一樣。

串列的作用，是給一組值取一個統一的名字。這些值，也叫元素，可以是任意型別。可以是 float、int、bool、字串，也可以是更高階的 Python 型別，甚至是串列本身。

串列裡包含不同型別的元素，也完全沒問題。

## Python 串列

```yaml
type: FullSlide
key: 35d6825cd6
code_zoom: 68
```

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
比如，假設你想把姐妹和父母的名字也加進串列裡，以便弄清楚每個身高分別對應誰。那麼，你可以直接把字串加進去，這完全沒問題。

但這還不是全部，我剛才提到過，串列還能再巢狀串列。與其把字串和數字交錯混放在一起，不如為每個家人單獨建一個獨立的子串列：liz 一個，emma 一個，以此類推。接著，你只需要告訴 Python 這些子串列都是另一個大串列的元素就行，這裡的大串列命名為 fam2。小串列的外層使用方括號括起來，彼此用逗號隔開。這時如果列印出 fam2，你會發現我們得到了一個「串列的串列」，大串列裡整整齊齊地套著 4 個子串列。

除了之前學過的字串、布林值、整數和浮點數之外，我們現在瞭解的是一種全新的 Python 資料型別：串列。
