`@script`
เราสร้าง list ได้โดยใช้วงเล็บเหลี่ยม สมมติว่าถามส่วนสูงของพี่สาว 2 คนและพ่อแม่ เป็นหน่วยเมตร ก็สร้าง list ได้ดังนี้

แน่นอนว่าโครงสร้างข้อมูลนี้ก็อ้างอิงด้วยตัวแปรได้เช่นกัน เพียงใส่ชื่อตัวแปรและเครื่องหมายเท่ากับไว้ข้างหน้า ดังตัวอย่างที่เห็น

list คือวิธีรวมค่าหลายค่าไว้ภายใต้ชื่อเดียว ค่าหรือสมาชิกแต่ละตัวจะเป็นชนิดใดก็ได้ ไม่ว่าจะเป็น float, int, bool, str หรือแม้แต่ list ก็ได้

ใน list เดียวกันจะมีค่าหลายชนิดปนกันก็ได้ด้วย

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
สมมติว่าต้องการเพิ่มชื่อของพี่สาวและพ่อแม่เข้าไปใน list เพื่อให้รู้ว่าส่วนสูงไหนเป็นของใคร เราก็ใส่ข้อความลงไปได้เลยโดยไม่มีปัญหา

แต่ยังมีอีก ที่บอกไปว่า list สามารถประกอบด้วย list ย่อยได้นั้น แทนที่จะสลับข้อความกับตัวเลข เราสร้าง list ย่อยให้สมาชิกแต่ละคนได้เลย อย่างของ liz, ของ emma และต่อ ๆ ไป จากนั้นบอก Python ว่า list ย่อยเหล่านี้คือสมาชิกของ list ชื่อ fam2 โดยใส่วงเล็บเหลี่ยมครอบและคั่นด้วยจุลภาค เมื่อพิมพ์ fam2 ออกมา จะเห็นว่าเป็น list ของ list โดย list หลักมี 4 list ย่อย

นี่คือชนิดข้อมูลใหม่ใน Python นอกเหนือจาก str, bool, int และ float ที่รู้จักกันไปแล้ว
