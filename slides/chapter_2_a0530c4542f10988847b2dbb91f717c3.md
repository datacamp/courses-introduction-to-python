```{{2}}

- 값 모음에 이름 지정{{3}}

- 모든 유형 포함 가능{{4}}

- 서로 다른 유형 포함 가능{{5}}

`@script`
리스트는 대괄호를 이용해 만들 수 있습니다. 두 언니와 부모님의 키를 물어봤다고 가정해 보겠습니다. 이때 단위는 미터입니다. 그럼 이렇게 리스트를 만들 수 있습니다.

물론, 이 데이터 구조도 변수로 참조할 수 있습니다. 앞에 변수 이름과 등호를 넣기만 하면 됩니다. 이렇게요.

리스트는 여러 개의 값을 하나의 이름으로 묶어서 표현하는 방법입니다. 이러한 값 또는 요소는 어떤 타입이든 가질 수 있습니다. 실수, 정수, 불리언, 문자열을 비롯하여 더 심화된 Python 타입이나 리스트까지도 가능합니다.

서로 다른 타입이 함께 리스트에 포함되는 것도 물론 가능합니다.

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
예를 들어, 언니들과 부모님의 이름을 목록에 추가해서 누구의 키가 몇 센티인지 나타내려고 한다면, 문자열을 추가해도 아무 문제 없습니다.

하지만 그게 다는 아닙니다. 방금 리스트 안에 리스트를 넣는 것도 가능하다고 말씀드렸는데요. 숫자 사이에 문자열을 넣는 대신, 각 가족 구성원별로 작은 하위 리스트를 만들 수 있습니다. 하나는 Liz, 하나는 Emma, 이런 식으로요. 이제 이 하위 리스트들이 또 다른 리스트의 요소라는 것을 Python에게 알립니다. 저는 이 리스트를 fam-2라고 이름지었습니다. 작은 리스트는 대괄호로 감싸고, 쉼표로 구분합니다. 이제 fam-2를 출력해 보면, 리스트 안에 리스트가 있는 것을 확인할 수 있습니다. 메인 리스트 안에 네 개의 서브 리스트가 있죠.

여러분이 이미 알고 있는 문자열, 불리언, 정수, 실수 외에 새로운 Python 타입을 다루고 있는데요.
