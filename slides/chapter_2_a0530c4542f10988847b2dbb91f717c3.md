`@part1`
- `[a, b, c]`


```py
[1.73, 1.68, 1.71, 1.89]
```{{1}}

```out
[1.73, 1.68, 1.71, 1.89]
```{{1}}

```py
fam = [1.73, 1.68, 1.71, 1.89]
fam
```{{2}}

```out
[1.73, 1.68, 1.71, 1.89]
```{{2}}

- 为数值集合命名{{3}}

- 包含任意类型{{4}}

- 包含不同类型{{5}}

`@script`
你可以用方括号来创建这样的列表。假设你向两位姐妹和父母询问了他们的身高，单位是米。列表可以这样建。

当然，这个数据结构也可以用变量名来引用。只要把变量名和等号放在前面，就像这里一样。

列表的作用，是给一组值取一个统一的名字。这些值，也叫元素，可以是任意类型。可以是 float、int、bool、字符串，也可以是更高级的 Python 类型，甚至是列表本身。

列表里包含不同类型的元素，也完全没问题。

## Python 列表

```yaml
type: FullSlide

```

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
比如，假设你想把姐妹和父母的名字也加进列表里，以便弄清楚每个身高分别对应谁。那么，你可以直接把字符串加进去，这完全没问题。

但这还不是全部，我刚才提到过，列表还能再嵌套列表。与其把字符串和数字交错混放在一起，不如为每个家人单独建一个独立的子列表：liz 一个，emma 一个，以此类推。接着，你只需要告诉 Python 这些子列表都是另一个大列表的元素就行，这里的大列表命名为 fam2。小列表的外层使用方括号括起来，彼此用逗号隔开。这时如果打印出 fam2，你会发现我们得到了一个“列表的列表”，大列表里整整齐齐地套着 4 个子列表。

除了之前学过的字符串、布尔值、整数和浮点数之外，我们现在了解的是一种全新的 Python 数据类型：列表。
