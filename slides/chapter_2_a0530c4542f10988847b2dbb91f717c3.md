Список позволяет хранить набор значений под одним именем. Элементы списка могут быть любого типа: вещественные числа, целые числа, логические значения, строки, а также более сложные типы Python, включая другие списки.

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
Допустим, вы хотите добавить имена сестёр и родителей к списку, чтобы понимать, какой рост кому принадлежит. Можно без проблем включить строки в тот же список.

Но это ещё не всё. Как я уже говорил, списки могут содержать другие списки. Вместо того чтобы чередовать строки и числа, можно создать небольшой подсписок для каждого члена семьи: один для Лиз, один для Эммы и так далее. Затем можно указать Python, что эти подсписки являются элементами другого списка, который я назвал fam2. Подсписки заключаются в квадратные скобки и разделяются запятыми. Если вывести fam2 на экран, вы увидите список списков: основной список содержит 4 подсписка.

Итак, мы познакомились с новым типом данных Python, наряду со строками, логическими значениями, целыми и вещественными числами.
