`@script`
你可以用方括號來建立這樣的串列。假設你向兩位姐妹和父母詢問了他們的身高，單位是公尺。可以像這樣建立串列。

當然，你也可以使用變數來參照這個資料結構。只要像這裡一樣，在前面加上變數名稱和等號。

串列讓你可以用單一名稱來表示一組值。這些值也叫元素，可以是任意型別，如浮點數、整數、布林值、字串，也可以是更進階的 Python 型別，甚至是串列。

而且，同一個串列裡可以包含不同型別的元素。

## Python 串列

```yaml
type: FullSlide
key: 35d6825cd6
code_zoom: 68
```

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
例如，假設你想把姐妹和父母的名字加入串列，這樣就能知道每筆身高資料分別屬於誰。你可以直接加入字串，完全沒問題。

但還不只如此，我剛才提過，串列本身也可以包含其他串列。你不必把字串穿插在數字之間，可以為每位家人建立一個子串列：liz 一個，emma 一個，以此類推。接著，你只需要告訴 Python 這些子串列都是另一個大串列的元素就行，這裡的大串列命名為 fam2：只要用方括號將這些小串列括起來，再用逗號分隔彼此。這時如果輸出 fam2，就會看到一個由多個串列組成的串列，最外層的大串列包含四個子串列。

除了之前學過的字串、布林值、整數和浮點數之外，我們現在瞭解的是一種全新的 Python 資料型別：串列。
