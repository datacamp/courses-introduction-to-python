- 複数の値に1つの名前を付けられる{{3}}

- どの型の値でも入れられる{{4}}

- 異なる型の値を混在させられる{{5}}

`@script`
このようなリストは角カッコで作成できます。 2人の姉妹と両親に、身長をメートルで聞いたとしましょう。 次のようにリストを作成できます。

もちろん、このデータ構造も変数名を付けることができます。 このように、先頭に変数名とイコール記号を置くだけです。

リストとは、複数の値をひとまとめにして、1つの名前で扱えるようにするデータ構造です。リストに入る値は要素と呼ばれ、どのような型でもかまいません。float（浮動小数点数）、i-n-t（整数）、bool（真偽値）、s-t-r（文字列）のほか、より高度なPythonの型、さらには別のリストを入れることもできます。

1つのリストに異なる型の要素が含まれていても、まったく問題ありません。

`@part1`
- `[a, b, c]`

```py
fam = ["liz", 1.73, "emma", 1.68, "mom", 1.71, "dad", 1.89]
```
```py
fam
```

```out
['liz', 1.73, 'emma', 1.68, 'mom', 1.71, 'dad', 1.89]
```

```py
fam2 = [["liz", 1.73],
		["emma", 1.68],
		["mom", 1.71],
		["dad", 1.89]]
```{{1}}
```py
fam2
```{{2}}

```out
[['liz', 1.73], ['emma', 1.68], ['mom', 1.71], ['dad', 1.89]]
```{{2}}

`@script`
たとえば、どの身長が誰のものか分かるように、姉妹や両親の名前をリストに追加したいとしましょう。いくつかの文字列を追加しても問題ありません。

しかし、それだけではありません。さっき、リストの中に別のリストを含めることもできると話しましたよね。数字の間に文字列を入れる代わりに、家族のメンバーごとに小さなサブリストを作成できます。lizに1つ、emmaに1つ、というふうに。ここでは、これらのサブリストが、fam2という別のリストの要素であることをPythonに伝えます。小さなリストは角カッコで囲み、カンマで区切ります。今、fam2を出力してみると、リストのリストになっていることがわかります。メインのリストには、4つのサブリストが含まれています。

ここでは、すでに知っているs-t-r、bool、i-n-t、floatに加えて、新しいPythonの型を扱っています。
