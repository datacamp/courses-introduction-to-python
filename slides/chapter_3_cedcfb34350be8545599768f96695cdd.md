`@script`
Innan du kan göra det behöver du importera paketet, eller en specifik modul ur paketet. Det gör du med import-satsen.

För att importera hela numpy-paketet skriver du import numpy, som här.

En ofta använd funktion i NumPy är array. Den tar en lista som indata. Att bara anropa funktionen array på det här sättet ger ett felmeddelande.

För att referera till funktionen array från numpy-paketet behöver du skriva så här.

Den här gången fungerar det. NumPy-arrayer är mycket användbara inom datavetenskap, men mer om det senare.

Att skriva prefixet numpy med punkt hela tiden kan bli ganska omständligt. Därför kan du importera paketet och ge det ett kortare namn. Det gör du genom att lägga till as i din import-sats, som här.

Nu använder du np.array i stället för numpy.array för att anropa NumPys array-funktion.

Det finns fall då du bara behöver en enda specifik funktion från ett paket. Python låter dig göra det tydligt i koden. Säg att du bara vill använda funktionen array från NumPy. I stället för import numpy kan du skriva from numpy import array, som här.

Då kan du anropa funktionen array direkt, utan att behöva skriva numpy med punkt.

Den här from import-varianten kan vara praktisk för att hålla koden kortare, men du förlorar en del av sammanhanget.
