`@script`
사용하기 전에 우선 패키지 또는 패키지의 특정 모듈을 가져와야 합니다. 이때는 import 명령문을 사용하면 됩니다.

numpy 패키지 전체를 가져오기 위해서 import numpy를 사용할 수 있습니다. 이렇게요.

NumPy에서 자주 사용되는 함수 중 하나는 array인데요. 리스트를 입력값으로 받습니다. array 함수를 이렇게 단순하게 호출하면 오류가 발생합니다.

numpy 패키지의 array 함수를 사용하려면 이렇게 해야합니다.

이번에는 작동하죠. NumPy array는 데이터 과학 분야에서 매우 유용합니다. 이 내용은 나중에 다루겠습니다.

항상 앞에 numpy dot을 붙이는 것은 상당히 번거롭기 때문에, 패키지를 가져와서 다른 이름으로 사용할 수도 있습니다. as를 사용하여 import 명령문을 확장하면 됩니다. 이렇게요.

이제 numpy.array 대신 np.array를 사용하여 NumPy의 array 함수를 사용할 수 있습니다.

패키지의 특정 함수 하나만 필요한 경우가 생길 수도 있는데요. Python에서는 이걸 코드에서 명시적으로 표현할 수 있습니다. 우리가 NumPy 패키지에서 array 함수만 사용하고 싶다고 가정해봅시다. import numpy를 사용하는 대신, from-numpy-import-array를 사용할 수 있습니다. 이렇게요.

이번에는 이렇게 간단하게 array 함수를 호출할 수 있습니다. numpy dot을 사용할 필요가 없죠.

패키지의 특정 부분만 사용하기 위해 from import 버전을 사용하는 건 작성할 코드 양을 줄이는 데는 유용할 수 있지만, 그 과정에서 일부 맥락을 잃게 될 수도 있습니다.
