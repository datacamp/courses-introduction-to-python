`@script`
在开始编写代码前，你要先导入这个包或它里面的特定模块，用 import 语句就能实现。
要导入整个 numpy 包，可以像这样写 import numpy。
NumPy 里有一个很常用的函数叫 array，它会接收列表作为输入。如果像这样直接调用 array()，Python 会报错。
正确的调用方法是带上包名：numpy.array(...)。
这次就能正常运行了！NumPy 数组在数据科学领域极为实用，后面我们会详细介绍。
不过每次都写 numpy. 这个前缀会让人感觉很麻烦，你可以在导入时给它起一个简短的“别名”。在 import 后面接上 as 就行，比如这样。
这样，你以后就不需要写 numpy.array 了，直接用 np.array 就能调用 NumPy 的数组函数。
有时，你可能只需要包里的某个特定函数，Python 也支持精准导入。假设你只需要使用 array 函数，就可以把 import numpy 改写为 from numpy import array。
这样，后续就能直接调用 array()，再也不用加 numpy. 前缀了。这种 from ... import ... 的导入方式能帮你少打不少字，但同时也会让你的代码失去一些表明来源的上下文信息。

## import numpy

`@part1`
```py
import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
从这一角度来看，写成标准的 import numpy 反而是更推荐的做法：在本例中，将函数调用写作 numpy.array，能让人一眼就看懂你正在调用的是 NumPy 中的工具。
