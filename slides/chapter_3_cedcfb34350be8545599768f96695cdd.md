`@part1`

```out

```py
numpy.array([1, 2, 3])
```{{4}}

```out
array([1, 2, 3])
```{{5}}

`@part2`
```py
import numpy as np
```{{6}}
```py
np.array([1, 2, 3])
```{{7}}

```out
array([1, 2, 3])
```{{8}}

```py
from numpy import array
```{{9}}
```py
array([1, 2, 3])
```{{10}}

```out
array([1, 2, 3])
```{{11}}

`@script`
Înainte de a face asta, trebuie să imporți pachetul sau un modul specific din el. Poți face asta cu instrucțiunea import.

Ca să imporți întregul pachet numpy, scrii import numpy, ca în exemplu.

O funcție des folosită în NumPy este array. Aceasta primește o listă ca argument. Dacă o apelezi direct, fără prefix, vei primi o eroare.

Ca să faci referire la funcția array din pachetul numpy, ai nevoie de sintaxa completă.

De data aceasta funcționează. Array-ul NumPy este foarte util în știința datelor, dar vom reveni asupra lui mai târziu.

Să scrii prefixul numpy punct de fiecare dată poate deveni obositor, așa că poți importa pachetul și să îi dai un alt nume. Faci asta extinzând instrucțiunea import cu as, ca în exemplu.

Astfel, în loc de numpy.array, vei folosi np.array pentru a apela funcția array din NumPy.

Sunt situații în care ai nevoie doar de o singură funcție dintr-un pachet. Python îți permite să fii explicit în privința asta. Să zicem că vrei să folosești doar funcția array din NumPy. În loc de import numpy, poți scrie from numpy import array, ca în exemplu.

De data aceasta, poți apela direct funcția array, fără a mai folosi prefixul numpy punct.

Această variantă cu from import este utilă pentru a reduce cantitatea de cod, însă pierzi o parte din context.

## import numpy

```yaml
type: FullSlide
key: b287cdae79
code_zoom: 70
```

`@part1`
```py
import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
Din acest motiv, varianta standard import numpy este de preferat. În acest caz, apelul funcției devine numpy.array, ceea ce arată clar că lucrezi cu NumPy.
