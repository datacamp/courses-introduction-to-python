`@script`
ในการใช้งาน Package ของ Python คุณต้องติดตั้งลงในระบบของคุณก่อน จากนั้นจึงเพิ่มโค้ดลงในสคริปต์เพื่อบอกให้ Python รู้ว่าจะใช้ Package เหล่านั้น

บน DataCamp มีการติดตั้ง Package ที่จำเป็นทั้งหมดไว้ให้แล้ว แต่ถ้าต้องการติดตั้งในระบบของตัวเอง ให้ใช้ pip ซึ่งเป็นระบบจัดการ Package ของ Python ไปที่ URL นี้เพื่อดาวน์โหลดไฟล์ get-pip.py จากนั้นเปิด Terminal แล้วรันคำสั่ง python3 get-pip.py เท่านี้ก็สามารถใช้ pip ติดตั้ง Package ที่ต้องการได้แล้ว สมมติว่าอยากติดตั้ง Package numpy ซึ่งจะได้เรียนในบทถัดไป ให้พิมพ์ pip3 install numpy โดยที่ต้องใช้คำสั่ง python3 และ pip3 เพื่อระบุว่ากำลังทำงานกับ Python เวอร์ชัน 3

เมื่อติดตั้ง Package เรียบร้อยแล้ว ก็สามารถนำไปใช้ในสคริปต์ Python ได้ทันที

```{{9}}

```{{10}}

```out
array([1, 2, 3])
```{{11}}

`@script`
ก่อนจะใช้งานได้ คุณต้อง import Package หรือ Module ที่ต้องการเสียก่อน โดยใช้คำสั่ง import

หากต้องการ import Package numpy ทั้งหมด ให้ใช้คำสั่ง import numpy แบบนี้

ฟังก์ชันที่ใช้บ่อยใน NumPy คือ array ซึ่งรับ List เป็น input การเรียกใช้ฟังก์ชัน array โดยตรงแบบนี้จะทำให้เกิด Error

ในการเรียกใช้ฟังก์ชัน array จาก Package numpy ให้ใช้รูปแบบนี้แทน

คราวนี้ทำงานได้แล้ว NumPy Array มีประโยชน์มากสำหรับงานวิทยาศาสตร์ข้อมูล แต่จะพูดถึงรายละเอียดในภายหลัง

การพิมพ์ numpy dot นำหน้าทุกครั้งอาจน่าเบื่อ คุณจึง import Package แล้วตั้งชื่อย่อให้มันได้ โดยต่อท้ายคำสั่ง import ด้วย as แบบนี้

จากนี้ แทนที่จะใช้ numpy.array ก็เปลี่ยนมาใช้ np.array แทนได้เลย

มีบางกรณีที่ต้องการเพียงฟังก์ชันเดียวจาก Package Python ให้คุณระบุสิ่งนี้ได้ชัดเจนในโค้ด สมมติต้องการแค่ฟังก์ชัน array จาก Package NumPy แทนที่จะใช้ import numpy ให้ใช้ from numpy import array แบบนี้แทน

คราวนี้สามารถเรียกใช้ฟังก์ชัน array ได้โดยตรงเลย โดยไม่ต้องพิมพ์ numpy dot นำหน้า

วิธี from import แบบนี้มีประโยชน์ช่วยลดปริมาณโค้ดได้ แต่ก็ทำให้บริบทของโค้ดชัดเจนน้อยลงด้วย
