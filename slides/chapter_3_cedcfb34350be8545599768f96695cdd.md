`@script`
在使用套件前，你要先匯入套件或套件中的特定模組，用 import 陳述式來完成這項操作。.

要匯入整個 NumPy 套件，可以像這樣寫 import numpy。

NumPy 中有一個常用的函式叫 array 陣列，它接受串列作為輸入。如果像這樣直接呼叫 array()，會出現錯誤。

正確的呼叫方法是帶上套件名稱：numpy.array(...)。

這樣就能正常執行！NumPy 陣列在資料科學領域極為實用，後面我們會詳細介紹。

不過每次都寫 numpy. 這個前綴感覺很麻煩，你可以在匯入時給它起一個簡短的別名。在 import 陳述式後接上 as 別名，比如這樣。

以後就不需要寫 numpy.array，直接用 np.array 就能呼叫 NumPy 的陣列函式了。

在只需要套件中的某個特定函式時，Python 也支援精準匯入。假設我們只想使用 array 函式，可以將 import numpy 改為 from numpy import array。

這麼做之後就能直接呼叫 array()，再也不用加 numpy. 前綴了。

這種 from ... import ... 的匯入方式能讓你少打不少字，但也會讓你的程式碼失去表明來源的資訊。

```py
import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
從這個角度來看，使用 import numpy 反而是更推薦的做法：呼叫函式時會寫作 numpy.array，讓人一眼就能看出你使用的是 NumPy。
