`@script`

Datacamp a déjà installé tous les paquets nécessaires pour vous, mais si vous souhaitez les installer sur votre propre système, vous utiliserez pip, un gestionnaire de paquets pour Python. Si vous allez à cette adresse URL, vous pouvez télécharger le fichier get-pip.py. Ensuite, ouvrez le terminal et exécutez python3 get-pip.py. Maintenant que le paquet est installé, vous pouvez réellement commencer à l'utiliser dans l'un de vos scripts Python.

```py

```{{9}}
```py
array([1, 2, 3])
```{{10}}

```out
array([1, 2, 3])
```{{11}}

`@script`
Avant de pouvoir le faire, vous devez importer le paquet, ou un module précis du paquet. Vous pouvez le faire avec l'instruction import.

Pour importer l'ensemble du paquet numpy, vous pouvez écrire import numpy, comme ceci.

Une fonction souvent utilisée dans NumPy est array. Elle prend une liste en entrée. Appeler simplement la fonction array ainsi générera une erreur.

Pour faire référence à la fonction array du paquet numpy, vous aurez besoin de ceci.

Cette fois, ça fonctionne. Le tableau NumPy est très utile pour faire de la science des données, mais nous y reviendrons.

Utiliser tout le temps le préfixe numpy point peut devenir plutôt lassant, donc vous pouvez aussi importer le paquet et y faire référence avec un autre nom. Vous pouvez le faire en prolongeant votre instruction d'importation avec as, comme ceci.

Désormais, au lieu de numpy.array, vous utiliserez np.array pour appeler la fonction array de NumPy.

Il y a des cas où vous n'avez besoin que d'une seule fonction d'un paquet. Python vous permet de le préciser explicitement dans votre code. Supposons que nous voulions seulement utiliser la fonction array du paquet NumPy. Au lieu de faire import numpy, vous pouvez faire from numpy import array, comme ceci.

Cette fois, vous pouvez simplement appeler la fonction array ainsi, sans avoir à utiliser numpy point.

Cette version with from import pour utiliser des parties précises d'un paquet peut être utile pour écrire moins de code, mais vous perdez aussi une partie du contexte.

## import numpy

```yaml
type: FullSlide

`@part1`
```py
import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Utilise clairement NumPy
```{{1}}

`@script`
À cet égard, l'appel plus standard import numpy est préférable : dans ce cas, votre appel de fonction est numpy.array, ce qui indique très clairement que vous travaillez avec NumPy.
