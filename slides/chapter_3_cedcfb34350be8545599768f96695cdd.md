- Терминал:{{3}}

	- `python3 get-pip.py`{{4}}

`@script`
Чтобы использовать пакеты Python, сначала нужно установить их на свой компьютер, а затем добавить в скрипт соответствующий код, чтобы Python знал, какие пакеты вы хотите использовать.

На платформе DataCamp все необходимые пакеты уже установлены. Однако если вы хотите установить их самостоятельно, вам пригодится pip, менеджер пакетов для Python. Перейдите по нужному адресу и скачайте файл get-pip.py. Затем откройте терминал и выполните команду python3 get-pip.py. После этого вы сможете устанавливать пакеты с помощью pip. Допустим, вы хотите установить пакет numpy, о котором пойдёт речь в следующей главе. Введите команду pip3 install numpy. Здесь важно использовать именно python3 и pip3, чтобы система знала, что вы работаете с третьей версией Python.

Когда пакет установлен, вы можете начать использовать его в своих скриптах.

`@script`
Прежде чем приступить к работе, нужно импортировать пакет или отдельный модуль из него. Для этого используется инструкция import.

Чтобы импортировать весь пакет numpy, напишите import numpy вот так.

Одна из популярных функций в NumPy называется array. Она принимает список в качестве аргумента. Если вызвать функцию array напрямую вот так, возникнет ошибка.

Чтобы обратиться к функции array из пакета numpy, нужно написать вот так.

Теперь всё работает. Массивы NumPy очень полезны в науке о данных, но подробнее об этом мы поговорим позже.

Постоянно писать префикс numpy с точкой может быть утомительно, поэтому пакет можно импортировать под другим именем. Для этого расширьте инструкцию import с помощью ключевого слова as, вот так.

Теперь вместо numpy.array нужно писать np.array, чтобы использовать функцию array из NumPy.

Бывают случаи, когда вам нужна только одна конкретная функция из пакета. Python позволяет явно указать это в коде. Допустим, нам нужна только функция array из пакета NumPy. Вместо import numpy можно написать from numpy import array, вот так.

В этом случае функцию array можно вызывать напрямую, без префикса numpy с точкой.

Такой способ импорта отдельных элементов пакета позволяет писать меньше кода. Однако при этом теряется часть контекста.
