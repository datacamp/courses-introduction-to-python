```{{8}}

```py

```{{9}}
```py
array([1, 2, 3])
```{{10}}

```out
array([1, 2, 3])
```{{11}}

`@script`
Zanim jednak to zrobisz, musisz zaimportować pakiet lub konkretny moduł. Służy do tego instrukcja import.

Żeby zaimportować cały pakiet numpy, użyj import numpy, tak jak tutaj.

Jedną z często używanych funkcji w NumPy jest array. Przyjmuje ona listę jako argument. Wywołanie funkcji array w ten prosty sposób spowoduje jednak błąd.

Żeby odwołać się do funkcji array z pakietu numpy, musisz zapisać to tak.

Teraz działa. Tablica NumPy jest bardzo przydatna w analizie danych, ale o tym powiemy więcej później.

Ciągłe wpisywanie prefiksu numpy z kropką może być męczące, dlatego możesz zaimportować pakiet pod skróconą nazwą. Wystarczy rozszerzyć instrukcję import o słowo kluczowe as, tak jak tutaj.

Od tej chwili zamiast numpy.array będziesz używać np.array, żeby wywołać funkcję array z NumPy.

Zdarza się, że potrzebujesz tylko jednej konkretnej funkcji z pakietu. Python pozwala ci to wyraźnie zaznaczyć w kodzie. Załóżmy, że chcesz używać wyłącznie funkcji array z pakietu NumPy. Zamiast import numpy możesz napisać from numpy import array, tak jak tutaj.

W tym przypadku możesz po prostu wywołać funkcję array bezpośrednio, bez żadnego prefiksu z kropką.

Ta wersja z from import bywa przydatna, bo skraca kod, jednak tracisz przy tym część kontekstu.
