`@script`
Python packages इस्तेमाल करने के लिए, पहले उन्हें अपने सिस्टम पर इंस्टॉल करना होगा, और फिर अपने script में ऐसा कोड लिखना होगा जो Python को बताए कि आप इन packages का उपयोग करना चाहते हैं.

Datacamp ने आपके लिए जरूरी packages पहले से इंस्टॉल कर रखे हैं, लेकिन अगर आप अपने सिस्टम पर इंस्टॉल करना चाहें, तो आप pip का उपयोग करेंगे, जो Python के लिए package management सिस्टम है. अगर आप इस URL पर जाएँ, तो get-pip.py फ़ाइल डाउनलोड कर सकते हैं. अगले चरण में, टर्मिनल में जाइए, और python3 get-pip.py चलाइए. अब आप pip का उपयोग करके अपनी पसंद का कोई भी Python package वास्तव में इंस्टॉल कर सकते हैं. मान लीजिए हमें numpy package इंस्टॉल करना है, जिसके बारे में आप अगले अध्याय में सीखेंगे. आप टाइप करेंगे pip3 install numpy. यहाँ python3 और pip3 इसलिए इस्तेमाल करना होगा, ताकि सिस्टम को बताएँ कि हम Python version 3 के साथ काम कर रहे हैं.

अब जब package इंस्टॉल हो गया है, तो आप इसे अपने किसी Python script में इस्तेमाल करना शुरू कर सकते हैं.

`@script`
इससे पहले, आपको package या उसके किसी विशेष module को import करना होगा. यह आप import स्टेटमेंट से कर सकते हैं.

पूरे numpy package को import करने के लिए, आप इस तरह import numpy लिख सकते हैं.

NumPy में एक आम तौर पर इस्तेमाल होने वाला function है array. यह इनपुट में एक list लेता है. अगर आप सीधे ऐसे ही array function को कॉल करेंगे, तो error आएगा.

numpy package के array function को संदर्भित करने के लिए, आपको यह लिखना होगा.

इस बार यह काम करता है. NumPy array data science करने में बहुत उपयोगी है, लेकिन उस पर हम बाद में आएँगे.

हर बार यह numpy डॉट लिखना थोड़ा थकाने वाला हो सकता है, इसलिए आप package को import करके उसे एक छोटा नाम भी दे सकते हैं. import स्टेटमेंट में as जोड़कर आप ऐसा कर सकते हैं, इस तरह.

अब, numpy.array की जगह, आपको NumPy के array function के लिए np.array इस्तेमाल करना होगा.

कई बार आपको किसी package का सिर्फ एक खास function चाहिए होता है. Python आपको यह बात अपने कोड में साफ तौर पर लिखने देता है. मान लीजिए कि हमें NumPy package से केवल array function का उपयोग करना है. import numpy करने के बजाय, आप लिख सकते हैं from numpy import array, इस तरह.

अब आप सीधे array function को ऐसे कॉल कर सकते हैं. यहाँ numpy डॉट लगाने की ज़रूरत नहीं है.

किसी package के विशेष हिस्सों को इस्तेमाल करने के लिए यह from import वाला तरीका टाइपिंग कम करा देता है, लेकिन आप थोड़ा संदर्भ खो देते हैं.
