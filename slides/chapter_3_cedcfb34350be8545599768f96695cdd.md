`@script`
在開始編寫程式碼前，你要先匯入這個套件或它裡面的特定模組，用 import 陳述式就能實現。
要匯入整個 numpy 套件，可以像這樣寫 import numpy。
NumPy 裡有一個很常用的函式叫 array，它會接收串列作為輸入。如果像這樣直接呼叫 array()，Python 會出現錯誤。
正確的呼叫方法是帶上套件名稱：numpy.array(...)。
這次就能正常執行了！NumPy 陣列在資料科學領域極為實用，後面我們會詳細介紹。
不過每次都寫 numpy. 這個字首會讓人感覺很麻煩，你可以在匯入時給它起一個簡短的「別名」。在 import 後面接上 as 就行，比如這樣。
這樣，你以後就不需要寫 numpy.array 了，直接用 np.array 就能呼叫 NumPy 的陣列函式。
有時，你可能只需要套件裡的某個特定函式，Python 也支援精準匯入。假設你只需要使用 array 函式，就可以把 import numpy 改寫為 from numpy import array。
這樣，後續就能直接呼叫 array()，再也不用加 numpy. 字首了。這種 from ... import ... 的匯入方式能幫你少打不少字，但同時也會讓你的程式碼失去一些表明來源的上下文資訊。

import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
從這一角度來看，寫成標準的 import numpy 反而是更推薦的做法：在本例中，將函式呼叫寫作 numpy.array，能讓人一眼就看懂你正在呼叫的是 NumPy 中的工具。
