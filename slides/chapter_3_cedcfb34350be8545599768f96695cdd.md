`@script`

У Datacamp уже встановлено всі потрібні пакети. Якщо ж хочете встановити їх на власній системі, скористайтеся pip, системою керування пакетами для Python. Припустімо, нам потрібно встановити пакет numpy, про який ви дізнаєтеся в наступному розділі. Введіть pip3 install numpy. Тепер, коли пакет встановлено, можна починати використовувати його у своєму Python-скрипті.

`@script`
Перш ніж це зробити, пакет або конкретний модуль пакета потрібно імпортувати. Використайте для цього оператор import.

Щоб імпортувати весь пакет numpy, напишіть import numpy, ось так.

Одна з найуживаніших функцій у NumPy — це array. Вона приймає список як вхідні дані. Якщо просто викликати функцію array ось так, ви отримаєте помилку.

Щоб звернутися до функції array з пакета numpy, потрібен ось такий запис.

Тепер усе працює. Масив NumPy дуже корисний для роботи з даними, але про це згодом.

Постійно набирати префікс numpy крапка може втомлювати. Тож можна імпортувати пакет і звертатися до нього під іншим іменем. Додайте до оператора import ключове слово as, ось так.

Тепер замість numpy.array ви використовуватимете np.array, щоб викликати функцію array з NumPy.

Бувають випадки, коли потрібна лише одна конкретна функція з пакета. У Python це можна явно зазначити в коді. Припустімо, нам потрібна тільки функція array з пакета NumPy. Замість import numpy можна написати from numpy import array, ось так.

Тепер можна просто викликати функцію array ось так, без префікса numpy.

Такий варіант from import, коли використовуємо окремі частини пакета, допомагає скоротити набір тексту. Проте ви втрачаєте частину контексту.
