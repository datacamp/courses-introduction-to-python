from numpy import array
```{{9}}
```py

```{{10}}

```out
array([1, 2, 3])
```{{11}}

`@script`
これを行う前に、パッケージ、またはパッケージ内の特定のモジュールをインポートする必要があります。これはimport 文で行うことができます。

numpy パッケージ全体をインポートするには、このように import numpy と書きます。

NumPyでよく使われる関数に array() があります。入力としてリストを受け取ります。このように array() 関数を呼び出すだけでは、エラーが発生します。

numpy パッケージの array() 関数を参照するには、このように書く必要があります。

今回はうまくいきました。NumPy配列はデータサイエンスを行う上で非常に便利ですが、詳しくは後ほど説明します。

このように毎回 numpy. を付けるのはかなり面倒なので、パッケージをインポートして、別の名前で参照することもできます。これを行うには、このように import 文に as を追加します。

これからは、numpy.array の代わりに np.array を使ってNumPyの array() 関数を利用する必要があります。

パッケージの特定の関数だけが必要な場合もあります。Pythonでは、これをコード内で明示的に示すことができます。NumPyパッケージの array() 関数だけを使いたいとしましょう。import numpy を使う代わりに、このように from numpy import array と書くこともできます。

今回は、このように array() 関数をそのまま呼び出すことができます。ここでは numpy. を付ける必要はありません。

パッケージの特定の部分を使うための from ... import ... の書き方は、書くコード量を減らすのに役立ちますが、その分、どのパッケージに由来するものなのかが少し分かりにくくなることもあります。

`@part1`
```py
import numpy as np

fam = ["liz", 1.73, "emma", 1.68, 
	"mom", 1.71, "dad", 1.89]

...
```
```py
fam_ext = fam + ["me", 1.79]

...
```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
その点では、より標準的なimport numpyの書き方が推奨されます。 この場合、関数呼び出しはnumpy.arrayになるので、NumPyを使っていることがとても明確になります。
