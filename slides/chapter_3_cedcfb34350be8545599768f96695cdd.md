`@script`
Než to uděláš, musíš balíček naimportovat — celý, nebo jen konkrétní modul. K tomu slouží příkaz import.

Celý balíček numpy naimportuješ takto: import numpy.

Často používanou funkcí v NumPy je array. Jako vstup přijímá seznam. Když funkci array zavoláš takhle přímo, dostaneš chybu.

Aby ses na funkci array z balíčku numpy odkázal správně, je potřeba napsat to takto.

Teď to funguje. NumPy pole je velmi užitečné pro datovou vědu, ale k tomu se dostaneme později.

Neustále psát předponu numpy s tečkou může být únavné, takže balíček můžeš naimportovat pod jiným názvem. Stačí rozšířit příkaz import o klíčové slovo as, takhle.

Místo numpy.array pak budeš psát np.array.

V některých případech potřebuješ z balíčku jen jednu konkrétní funkci. Python ti umožňuje to v kódu přímo vyjádřit. Řekněme, že chceme použít jen funkci array z balíčku NumPy. Místo import numpy napíšeš from numpy import array, takhle.

Tentokrát můžeš funkci array zavolat přímo, bez předpony numpy s tečkou.

Tato varianta from import je užitečná pro zkrácení kódu, ale ztrácíš tím část kontextu.

```
```py
fam_ext = fam + ["me", 1.79]

```
```py
print(str(len(fam_ext)) + " elements in fam_ext")

...
```
```py
np_fam = np.array(fam_ext) # Clearly using NumPy
```{{1}}

`@script`
V tomto ohledu je lepší standardní zápis import numpy: volání funkce pak vypadá jako numpy.array, a je tak hned jasné, že pracuješ s NumPy.
