`@script`
NumPy는 수치 계산을 위한 효율적인 데이터 구조를 제공할 뿐만 아니라 이런 작업 수행에도 뛰어납니다.

우선, NumPy의 mean 함수를 사용해 5000명의 평균 키를 구해볼 수 있습니다. NumPy 패키지의 함수이므로, np.로 시작해야 합니다.

부분 추출 연산을 먼저 진행해 2차원 배열에서 height 열을 가져왔습니다. 사람들의 평균 키는 1.75미터인 것 같군요. 그렇다면 키의 중앙값은 어떻게 될까요? 중앙값은 모든 사람을 키 순서로 정렬했을 때, 가운데 사람의 키를 나타내는 값입니다. 복잡한 Python 코드를 작성하는 대신, NumPy의 median 함수를 사용해 간단히 값을 구할 수 있습니다.

np_city의 weight 열에 대해서도 비슷한 작업을 할 수 있죠. 이러한 요약 통계로 데이터가 정상적인지 확인해보는 경우가 많습니다. 평균 몸무게가 이천 킬로그램이 나왔다면, 측정값이 잘못되었을 가능성이 높습니다.

mean과 median 외에도 다른 다양한 함수가 있는데요.

`@script`
키와 몸무게의 상관관계를 확인할 때 사용하는 corr-coeff나 표준편차를 구할 때 사용하는 std 등이 있습니다.

NumPy에는 Python 배포판에도 존재하는 sum과 sort 등의 기본적인 함수도 갖추고 있습니다. 하지만 가장 큰 차이점은 속도입니다. NumPy는 배열에 하나의 데이터 유형만을 적용하기 때문에 계산 속도를 크게 높일 수 있습니다.

	- 분포 평균{{1}}

```py
height = np.round(np.random.normal(1.75, 0.20, 5000), 2)

weight = np.round(np.random.normal(60.32, 15, 5000), 2)

```{{1}}
```py
np_city = np.column_stack((height, weight))
```{{2}}

`@script`
참고로 덧붙이자면, 이 영상에 사용된 데이터를 만들어 낼 때도, NumPy 함수를 이용해 시뮬레이션했습니다! 저는 두 개의 무작위 분포를 오천 번 샘플링하여 키와 몸무게 배열을 만들었고, 그런 후에 column stack을 사용하여 두 배열을 두 개의 열로 붙였죠. NumPy로 이런 것도 가능하답니다!
