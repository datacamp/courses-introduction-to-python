## NumPy

```yaml

`@part1`
```py
np.mean(np_city[:, 0])
```{{1}}

```out
1.7472
```{{1}}

```py
np.median(np_city[:, 0])
```{{2}}

```out
1.75
```{{2}}

`@script`
NumPy — это не только эффективная структура данных для работы с числами, но и удобный инструмент для подобных вычислений.

Для начала можно найти средний рост этих 5000 человек с помощью функции mean из NumPy. Поскольку это функция из пакета NumPy, не забудьте написать префикс np. перед её именем.

Конечно, сначала нужно выделить столбец роста из двумерного массива. Оказывается, что в среднем рост людей составляет 1,75 метра. А что насчёт медианного роста? Это рост человека, который окажется ровно посередине, если выстроить всех от самого низкого до самого высокого. Вместо того чтобы писать сложный код на Python, вы можете просто воспользоваться функцией median из NumPy.

Аналогичные операции можно выполнить и для столбца веса в массиве np_city. Сводная статистика часто помогает проверить, насколько данные вообще правдоподобны. Если, например, средний вес окажется равным 2000 килограммов, это верный признак ошибки в измерениях.

Помимо среднего значения и медианы, в NumPy есть и другие функции.

- sum(), sort(), ...{{2}}

`@script`
Например, функция corrcoef позволяет проверить, есть ли корреляция между ростом и весом.

А функция std вычисляет стандартное отклонение.

В NumPy также есть более базовые функции: sum и sort. Они присутствуют и в стандартной библиотеке Python. Главное отличие — скорость работы. Поскольку NumPy хранит в массиве данные только одного типа, вычисления выполняются значительно быстрее.

## Генерация данных

```yaml
type: FullSlide
key: 0c27803967
code_zoom: 80
```

`@part1`
- Аргументы `np.random.normal()` {{1}}
	- среднее распределения{{1}}
    - стандартное отклонение распределения{{1}}
    - количество выборок{{1}}

```py
height = np.round(np.random.normal(1.75, 0.20, 5000), 2)

weight = np.round(np.random.normal(60.32, 15, 5000), 2)

```{{1}}
```py
np_city = np.column_stack((height, weight))
```{{2}}

`@script`
Небольшое замечание: если вам интересно, откуда взялись данные из этого видео — мы сгенерировали их с помощью функций NumPy. Я взял два случайных распределения и выполнил 5000 выборок из каждого, чтобы получить массивы роста и веса, а затем объединил их в два столбца с помощью функции column_stack. Ещё один пример того, на что способен NumPy.

Отличный способ лучше понять свои данные — это визуализировать их. Но это тема уже следующего курса.
